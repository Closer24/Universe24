If the cube and experiment selector do not appear

This may be a file preview that does not run JavaScript, or the viewer may have failed to start. This page cannot enable scripting inside another app.

Download the HTML file and open it in a current desktop browser. If your device only shows a file preview, use a browser-accessible copy of the same file. No recordings need to be recreated.

The interactive viewer needs JavaScript, BigInt, Canvas 2D and Web Crypto SHA-256. A static preview cannot play or rotate the cube.

Provenance, exactness & limits

Clocks and gears visualize stored integers and Rule3. Drawing a clock does not establish physical time, light or particles. Replay reads saved states and never changes evolution, coupling or connectivity.
