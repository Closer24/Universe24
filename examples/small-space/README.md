# Retired small-space comparisons

The 24-case small-space harness, its two private input configurations and its
three acceptance tests were removed from the active checkout during cleanup.
The [historical experiment package](https://github.com/Closer24/Universe24/tree/4796cb256cbdbd830aa29cc3038fea98087de58b/examples/small-space)
retains all results, inputs and limitations at the last retained revision.

The removed cases covered catalog probes, source responses and restricted
finite-reservoir and zero-total-momentum candidates. They did not establish
universal collision, field or gravity laws; their historical outcomes are no
longer current acceptance gates.

Current owners remain covered by [atomic interactions](../../docs/DISTURBANCES.md),
[spatial couplings](../../docs/SPATIAL_COUPLINGS.md),
[finite fields](../../docs/SPATIAL_FIELDS.md) and the
[catalog compiler](../../docs/ENTITY_CATALOG.md).
The shared [source sign notes](source-notes.md) remain for the charged-pair example.
