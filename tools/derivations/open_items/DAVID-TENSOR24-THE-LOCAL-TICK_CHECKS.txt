## 1. The words and the state

- The Node-clock x, its six Spokes j in the head's order (core/spokes.py, SPOKE_SIDES), its six neighbours y = x + e_j on the torus. The great clock's notch is only the unit every dial counts in (section 2.4).
- The state at x is the new engine's (plan section 31: every gear's notch now n and before b, its fine tooth r in [0, W), its drive fine tooth), plus one integer: **the dial tau_x, the great clock's notch at which x's now stands**.
- The regulator's time gear at x has its two slots, X now and X- before (the stretch, s = X). Its fine tooth lies in [0, T_r), its drive fine tooth in [0, T_d).
- **The local tick.** The tick from x's before to its now lasts L(X-, X) = lambda(X-) + lambda(X) notches. lambda is the count of notches per half tick at one slot of the time gear; the proofs ask only that lambda be an integer of at least 1, read from the slot.
- **The before-notch** sigma_x = tau_x - L(X-_x, X_x) is a function of the state. It is not stored.
- The probes use lambda = X, lambda = X + X X div 1000, L = W+ itself (lambda = (T div 2) X), and lambda = 1 + X X (section 2.5); a1 also runs lambda constant (the head).

## 2. The local tick and the step

### 2.1 The event E_x

x is due at its own notch tau = tau_x. The event does five acts:

1. **(R) the reads.** For every neighbour y and every gear the step reads across the Mesh:

       u = tau - sigma_y,   L_y = tau_y - sigma_y,   m = b_y + R((n_y - b_y) u, L_y),   R(k, L) = (k + mid L) div L

   R is Rule3's quotient with the mid tooth, acts.carry(k, L, mid L), the carry's own rounding. In clock words: each Spoke reads the neighbour's hand where it stands at this Node-clock's own notch, on the neighbour's current tick, between its before and its now.
2. **(I) the impulse** (Cut 0's matter half):

       W = (T div 2)(X- + X),  s = X
       P = W (a - a-) + (r - mid W)
       P+ = P + s F + K,  F = SUM_j g_j (m_j - a) - D a + q_P,  K = T s q_K

3. **(G) the regulator** (Cut 0's metric half). Its turn at its own teeth reads its gears' values m_j at the moment; its drive is one carry of its numerator. The numerator reads P and P+ symmetrically, as u_in u_out does, and the middle slot.
4. **(C) the carry** at W+ = (T div 2)(X + X+): a+ = a + (P+ + mid W+) div W+, and r+ is the remainder.
5. **(D) the dial:** tau+ = tau + L(X, X+).

The order of the acts is forced:
- the carry needs W+, so the regulator's step comes before it;
- the regulator's source reads P and P+, so the impulse comes before the regulator.

This is section 31's "schedule of two stages", inside one event.

**The step stays one local event. PROVED** by reading E_x:
- it writes only x's integers;
- it reads only x and, at each of its six neighbours, the notches now and before of the gears it reads, the time gear's two slots (for L_y) and the dial tau_y.

### 2.2 The endpoint lemma

**PROVED.** R((n - b) 0, L) = 0 and R((n - b) L, L) = n - b. The reason: (k L + mid L) div L = k + (mid L) div L = k, since 0 <= mid L < L for every L >= 1. So a read at u = 0 is the before b exactly, and a read at u = L is the now n exactly. Exhaustively CHECKED in a8 (54,872 reads, 0 off) for the three reads of section 3.

### 2.3 The conservative rule, and why every read falls on a tick

The runner's rule (Chandy and Misra's, on the stencil): **x is due when tau_x <= tau_y at each of its six neighbours.** In three operations it is the product over the six Spokes of [tau_y - tau_x >= 0], with [n >= 0] = 1 + n div (n n + 1) (plan section 31).

**Lemma 1. PROVED.** When x is due, every neighbour's current tick holds x's moment: sigma_y <= tau_x <= tau_y.
- tau_x <= tau_y is the rule itself.
- sigma_y is the notch of y's last event. When y stepped, it was due, so sigma_y <= the dial x had then, which is <= tau_x, since dials only grow.
- The start: every Node-clock's before-notch lies below every neighbour's now-notch (the probes start every dial in [0, L)).

**Lemma 2. PROVED.** On every Mesh, |tau_x - tau_y| <= max(L_x, L_y).
- When x steps, tau_x <= tau_y, so its new dial is at most tau_y + L_x.
- y's dial is at most tau_x + L_y, by the same step at y.
- So a Node-clock may hold its dial modulo any M > 2 max L, and every difference the step reads is still exact. No number of the great clock is held.
- CHECKED a2: the largest |tau_x - tau_y| / max(L_x, L_y) on any Mesh is exactly 1.

There is no deadlock: the least dial on the board is always due.

### 2.4 The head is the asynchronous board at one tick

**Theorem 1. PROVED.** Suppose every Node-clock has the same tick at every count of ticks and the same starting dial. Then every run under the rule, in any order, one event at a time or all at once double-buffered, gives the head's synchronous step bit for bit at every count.

Proof, by induction on the count. At the count k every dial reads the same notch, so every Node-clock is due. When x steps at that notch, each neighbour y is in one of two states:
- it has not stepped: its now-notch is the moment, u = L, and the read is n_y, its now at the round's start;
- it has stepped: its before-notch is the moment, u = 0, and the read is b_y, which its own step set to its now at the round's start.

Either way the read is the start board's now, the head's m_j, and x's own integers are its start's. So x's new integers are the head's. After the round every dial reads the next notch. QED.

"The same rate" means the same L:
- lambda constant: the head's one great clock's tick, the lapse only in the coefficients W, s, D, g_j;
- or lambda(X) with X alike at every Node-clock; the common tick may still slow or speed (a1, case B).

**The unit of the notch. PROVED.** Only differences and ratios of dials enter the step (u and L_y), and the read depends on u / L_y alone: floor(k / L + 1/2) is a function of the rational number k / L. So shifting every dial, or multiplying every dial and every L by one integer, gives the same run. This is how "possible when it is very large" costs nothing: the great clock's notch may be as fine as wanted. CHECKED a5 E: lambda = X against L = W+ ((T div 2) times finer), 12 boards, 0 differ.

### 2.5 The tick at every integer

The plan's law that landed while this was written (08ec59132, section 12): "nothing holds an integer of the state inside a range, so no clamp ..., no floor value and no range. Where an act needs one to keep a symmetry or to stay defined, it is rewritten from the symmetries to hold at every integer".

The local tick needs L(X-, X) >= 1: a tick of 0 notches stalls the dial, and a negative one runs it back past its neighbours (Lemma 1 fails).
- **lambda = X, the probes' first choice, asks X >= 1: a range on the state, struck under that law.**
- **PROVED:** lambda = 1 + X X gives L = 2 + X- X- + X X >= 2 at every integer pair, with no range, no clamp and no comparison. It is even under X -> -X, and symmetric in the two slots as section 4.3 needs.

## 3. The order-free reads

### 3.1 Two events at one notch commute

**Theorem 2. PROVED.** If x and y are both due at the notch tau, then E_x E_y = E_y E_x on the whole board.

Proof:
- E_x writes only x.
- If y is no neighbour of x, neither event reads what the other writes.
- If y is a neighbour, E_x reads y only through (R) at the moment tau:
  - before E_y, y's tick is [sigma_y, tau]: u = L_y and the read is n_y;
  - after E_y, y's tick is [tau, tau + L_y'], u = 0, and the read is b_y'. E_y set b_y' to n_y, the same integer.
  - y's dial and slots enter E_x only through u and L_y, inside this same read.
- The same holds for E_y. QED.

**Corollary. PROVED.** Every run under the conservative rule executes the events below a given notch with the same results, whatever its order. This covers the great clock's order with any ties, a random local minimum at a time, and every local minimum at once double-buffered. Proof: by induction over the events of any such run. The k-th event reads values written by events already executed, at the same moments the great clock's order reads them. By Lemma 1, a neighbour's current tick there either is the same or differs by an event at the same notch, which Theorem 2 makes invisible. This is line 37's and line 98's "the same bit for bit, whatever the order was", extended from equal counts of ticks to clocks of different rates.

CHECKED a2, sides 3, 4 and 5:
- the boards: two rates (X 1000 and 2000), three rates (1000, 1500, 2000), or every Node-clock its own rate; every phase at 0, or random; the reads lin, past and near; the full formula with the time gear driven both ways;
- 432 runs on 54 boards; the reference runs held 56,327 events, 3,963 of them at a tie with a neighbour;
- 0 boards whose runs disagree;
- the mutants fail on 6 of 6 boards each: zoh_now (the value last sent), and slope_read (the value plus the neighbour's stride n - b).

### 3.2 What a read may be

The proof of Theorem 2 needs every read across a Mesh to be **a value at the moment**: a notch on the neighbour's current tick, exact at its ends.

Three kinds of read fail it (**PROVED** by Theorem 2's own case: the neighbour's event at the same notch changes each of them):
- a neighbour's fine tooth, drive fine tooth or counter: one slot, overwritten by its event;
- a neighbour's stride n - b: its event moves it to the next tick's;
- a neighbour's before: a second moment, lost to its event.

The head makes such reads at its start board (section 7, item 3d). h1 counts them at the head's own one tick taken as local events:
- the ratchet's stride (the centred count the Mesh offsets read): 237 of 27,000 reads on nature change with the order;
- every other gear's fine tooth: 45 percent of the reads change;
- every other gear's stride: 17 percent change.

They must become value reads before the board can run asynchronously (OPEN, section 10).

### 3.3 The weight of the read

Write the read as m = b + R((n - b) w(u, L)). Three laws constrain the weight w (**PROVED**):

1. **w(0) = 0 and w(L) = 1:** order-free (Theorem 2) and the head at one tick (Theorem 1).
2. **w(L - u) = 1 - w(u):** the read is unchanged when the slots are exchanged and the moment reflected. This is what the turnover's retrace needs (section 4.3).
3. **The support of w** (the least u at which the new slot is seen) bounds how fast a word crosses a Mesh in notches (section 5.4).

**Lemma 3. PROVED.** A weight with law 2 is above 0 by u = (L + 1) div 2: at u = L / 2 it is 1 / 2, and at odd L one of w((L - 1) / 2) and w((L + 1) / 2) is above 0. So **no time-symmetric read waits a whole tick**.

The three reads of the probes:
- **lin**, w = u / L: Lew, Marsden, Ortiz and West's interpolation of a node's trajectory, second order. Laws 1 and 2 hold; it sees the new slot at u = 1.
- **near**, w = (1 + sgn(2u - L)) / 2: the nearer slot, and the slots' mean at the midpoint, with sgn(k) = k div (k k + 1) - (-k) div (k k + 1). Laws 1 and 2 hold; it sees the new slot at u = L / 2.
- **past**, w = u div L: the slot last passed. Law 1 holds, law 2 fails; it sees the new slot only at u = L.

CHECKED a8 over L = 1 to 16 and every u, n, b in [-9, 9] (54,872 reads each):
- the endpoints fail 0, 0 and 0;
- the time symmetry fails 0, 0 and 41,040;
- the first u at which the new slot is seen at L = 16: 1, 8 and 16.

**The tie.**
- With R half up, the read keeps law 2 at every integer, ties included: (k + j L + mid L) div L = j + (k + mid L) div L.
- It is not odd under the negation of a gear at a tie, where (n - b) u / L is a half-integer, which happens only at even L.
- The head's odd rounding (rates.rounded) keeps the negation and loses law 2 at the same ties.
- **No integer rounding keeps both** (PROVED: R(-x) = -R(x) and R(1 - x) = 1 - R(x) at x = 1/2 ask R(1/2) = 1/2).

CHECKED a5 D, 56,250 small-integer reads with 3,984 ties:
- half up: the negation fails at the 3,984 ties and the time symmetry at 0;
- odd: the reverse;
- at odd L: neither fails.

This matters only for the gears the 24 negate (T1, T2, A2). It is the same decision as the carry's own tie rule (plan section 31, risk 2; section 30, item 5) and must be taken with it (OPEN).

### 3.4 The partition the 24 make (asked, derived, and not needed)

**Theorem 3. PROVED.** Let G be the group the 24 rotations about every Node-clock generate.

On Z^3:
- every rotation about a site p, v -> p + M (v - p), keeps the parity of x + y + z, since a signed permutation does;
- G holds the translations by e_a + e_b, a quarter turn about p composed with the inverse quarter turn about p + e_a, and with them D3, every even-sum translation;
- D3 is transitive on each parity class. So **G has exactly two orbits, the parity classes**, and no Mesh joins two Node-clocks of one class, since a Mesh changes one coordinate by 1.

On the torus of side n:
- at even n the same two classes stand;
- at odd n, 2 is invertible modulo n, so the translations by 2 e_a give every translation, and G has one orbit. The Meshes' graph then has cycles of odd length n, so no split into two Mesh-free classes exists at all.

Margolus's block partition:
- the 24 about one Node-clock split the eight corners Z^3 / 2 Z^3 of his block as 1 + 3 + 3 + 1;
- the parity of x + y + z joins them into the two classes, 4 + 4;
- his blocks are kept by the 24 only about the block's centre, which is no Node-clock.

**Inside a class, any order. PROVED for any read whatsoever:** two Node-clocks of one class share no Mesh, so neither event reads what the other writes.

CHECKED a3:
- sides 3, 4, 5 and 6: the orbits are 1, 2, 1, 2. At the even sides each orbit is one parity class, with 0 Meshes inside it of 192 and of 648. At the odd sides the one orbit holds all 81 and 375 Meshes, and no two-colouring exists.
- the 24 about the origin on the eight corners: orbits 1, 3, 3, 1.
- the blocks are kept by 3 of the 24 about a Node-clock, and by 24 of 24 about the block centre.
- at side 4, every notch a tie for all, with the order-dependent mutants zoh_now and slope_read: 24 runs each that take one class first, in random orders inside the class, give 0 distinct end states. The class taken first matters on 3 of 3 boards, and a one-Mesh translation parts the run from its image on 3 of 3. With the value read lin, none of the three matters.

**What the partition costs:**
- it needs an even side: a typed parity of the board, which the end check refuses (plan section 12, "No typed condition");
- it chooses an order between the two classes;
- it breaks the odd translations (the translation by one Mesh swaps the classes);
- on an odd torus there is none.

**So the board takes no partition.** It is order-free by value reads alone, on every side; it is Lemma 1 with Theorem 2 that frees the order, not a colouring. This agrees with the architect's note in section 31 ("their partitions are avoided, since they break the 24 at every tick").

## 4. The exact rewind

### 4.1 One event undone

    (D^-1) tau = tau+ - L(X, X+)                       X, X+: the time gear's slots after the event

    (C'^-1) a - a- = (P + mid W) div W,  r = the remainder,  W = (T div 2)(X- + X)

Proof:
- Every forward act is either a shear that adds to a slot a function of slots it leaves alone, or a carry n + r = q d + r' with 0 <= r < d. acts.carry at going -1 gives the carry's unique pre-image (the division algorithm, law 1).

- The regulator's numerator is symmetric in P and P+ and read at the middle slot, so (G^-1) recomputes it.
- The undo reads at the same moment the same neighbours as the event did (Lemma 4).
- The tick, read from the slots (D^-1), tells the undo its own moment, with no log and no stack.

**Lemma 4. PROVED.** Take the reverse rule: undo the Node-clock whose before-notch is a local maximum (or the greatest on the board).

- Undoing x's event changes no value any remaining event read, since those read x at moments at or before sigma_x, which x's last event does not move.

## 9. Prior art, and what is taken from each

- **Nakamura (1974), "Asynchronous cellular automata and their computational ability"; Toffoli (1978), on the phase-difference relations of asynchronous sequential networks; Nehaniv (2004), "Asynchronous automata networks can emulate any synchronous automata network".** A cell keeps its present and its past state and a local count, and steps only when its neighbours are not behind, reading the state of the right count. Taken: the two slots and the dial are that construction. Lemma 2 is its bound on the neighbours' counts, which lets a dial be held modulo a turn.
- **Toffoli and Margolus (1987; 1990, "Invertible cellular automata: a review"); Margolus (1984), "Physics-like models of computation".**
  - Taken: Fredkin's second-order form, and the shear that inverts exactly when it leaves its controls untouched (Theorem 4).
  - Derived and set aside: the block partition. It keeps the 24 only about the block's centre (section 3.4), as the architect found.
- **Lew, Marsden, Ortiz and West (2003), "Asynchronous variational integrators", Arch. Rational Mech. Anal. 167.**
  - Taken: every degree of freedom moves on its own clock; a force is read with every neighbour interpolated linearly to the force's moment (the read lin).
  - Their element step keeps the momentum exactly because an element's impulse reaches all its nodes at one moment; the Node-clock's step does not, hence section 5.2's residue.
  - AVIs keep the energy only nearly, and can show resonances at some ratios of steps (Fong, Darve and Lew, 2008); stability here is unprobed beyond about 20 ticks (section 10).
- **Chandy and Misra (1979), Bryant (1977); Lamport (1978); Jefferson (1985), "Virtual time"; Carothers, Perumalla and Fujimoto (1999), reverse computation.** The conservative rule (a Node-clock steps when no neighbour is behind its notch) gives the sequential result in any order, with no rollback. The rewind is reverse computation with no state saved, every act its own inverse. Time Warp's optimistic rollback is not needed, since the conservative rule never steps out of order.
- **Local time stepping for the wave equation.** Collino, Fouquet and Joly (2003); Diaz and Grote (2009), "Energy conserving explicit local time stepping for second-order wave equations"; Piperno (2006); Osher and Sanders (1983); Berger and Oliger (1984); Berger and Colella (1989). Conservation across an interface of two step sizes needs one flux booked for both sides: refluxing, or the energy-conserving interface. That is the way out named in section 5.2 and not derived.

        if self.lam == 'sq':          # 1 + X X: at least 1 at every integer, with no range on X
            return 1 + x * x
        if self.lam == 'const':
            return self.const
        raise KeyError(self.lam)

    def L(self, xa, xb):
        """The local tick from a Node-clock's two time-gear slots, symmetric in them."""
        if self.lam == 'W':
            return mean_teeth_of(self.T, xa, xb)
        if self.mutant == 'L_asym':
            return self.lam_of(xb) + self.lam_of(xb)
        return self.lam_of(xa) + self.lam_of(xb)


def read_value(n, b, u, L, P):
    """The neighbour's notch at the moment, u notches into its current tick of L notches."""
    R = ROUNDINGS[P.rnd]
    if P.mutant == 'zoh_now':        # the value it last sent, whatever the moment
        return n
    if P.mutant == 'wrong_end':      # the weight measured from the wrong end
        return b + R((n - b) * (L - u), L)
    if P.mutant == 'slope_read':     # the value read, plus the neighbour's stride (n - b): a slope read
        return b + R((n - b) * u, L) + (n - b)
    if P.read == 'lin':
        return b + R((n - b) * u, L)
    if P.read == 'past':             # the slot last passed: b + (n - b) [u = L], [u = L] = u div L
        return b + (n - b) * (u // L)
    if P.read == 'near':             # the nearer slot, the two slots' mean at the midpoint: w2 = 1 + sgn(2u - L)
        k = u + u - L
        sgn = k // (k * k + 1) - (-k) // (k * k + 1)
        return b + R((n - b) * (1 + sgn), 2)
    raise KeyError(P.read)


class Board:
    """A cube torus of side n, its Node-clocks indexed x + n (y + n z), the six neighbours in the head's Spoke order."""

    def __init__(self, n):
        self.n, self.N = n, n ** 3
        self.coords = [(i % n, (i // n) % n, i // (n * n)) for i in range(self.N)]
        self.nb = []
        for c in self.coords:
            row = []
            for axis, side in SPOKE_SIDES:
                d = list(c)
                d[axis] = (d[axis] + side) % n
                row.append(d[0] + n * (d[1] + n * d[2]))
            self.nb.append(row)
        assert len(self.nb[0]) == SPOKES

    def index(self, c):
        n = self.n
        return (c[0] % n) + n * ((c[1] % n) + n * (c[2] % n))


FIELDS = ('n3', 'n12', 'b3', 'b12', 'r3', 'r12', 'X', 'Xb', 'rX', 'dX', 'tau')


class State:
    def __init__(self, board):
        self.board = board
        for f in FIELDS:
            setattr(self, f, [0] * board.N)

    def copy(self):
        s = State(self.board)
        for f in FIELDS:
            setattr(s, f, list(getattr(self, f)))
        return s

    def key(self, with_tau=True):
        return tuple(tuple(getattr(self, f)) for f in FIELDS if with_tau or f != 'tau')

    def own(self, x):
        return tuple(getattr(self, f)[x] for f in FIELDS[:-1])

    def write(self, x, vals):
        for f, v in zip(FIELDS[:-1], vals):
            getattr(self, f)[x] = v

    def sigma(self, x, P):
        return self.tau[x] - P.L(self.Xb[x], self.X[x])


def build(n, P, pattern, phases, seed, amp=100, vamp=100):
    """A board with random hands, a time gear per Node-clock from the pattern, and the phases of the dials."""
    rng = random.Random(seed)
    board = Board(n)
    st = State(board)
    for x in range(board.N):
        c = board.coords[x]
        X = pattern(c, rng)
        st.X[x], st.Xb[x] = X, X
        st.n3[x], st.n12[x] = rng.randint(-amp, amp), rng.randint(-amp, amp)
        st.b3[x], st.b12[x] = st.n3[x] - rng.randint(-vamp, vamp), st.n12[x] - rng.randint(-vamp, vamp)
        W = mean_teeth_of(P.T, st.Xb[x], st.X[x])
        st.r3[x], st.r12[x] = rng.randrange(W), rng.randrange(W)
        st.rX[x], st.dX[x] = rng.randrange(P.Tr), rng.randrange(P.Td)
        L = P.L(st.Xb[x], st.X[x])
        st.tau[x] = 0 if phases == 'zero' else rng.randrange(L)
    return st


def reads_at(st, x, moment, P):
    """The six neighbours' values at the moment: the hand's two gears and the time gear."""
    out = []
    for j, y in enumerate(st.board.nb[x]):
        if P.mutant == 'reach2' and j == 0:     # a read two Meshes away along +X
            y = st.board.nb[y][0]
        Ly = P.L(st.Xb[y], st.X[y])
        u = moment - (st.tau[y] - Ly)
        if not 0 <= u <= Ly:
            raise Causality((x, y, moment, st.tau[y], Ly))
        out.append((read_value(st.n3[y], st.b3[y], u, Ly, P),
                    read_value(st.n12[y], st.b12[y], u, Ly, P),
                    read_value(st.X[y], st.Xb[y], u, Ly, P)))
    return out


def pull(P, n3, n12, reads):
    """F = SUM_j g (m_j - n) - d n, per gear."""
    f3 = sum(P.g * (m[0] - n3) for m in reads) - P.d * n3
    f12 = sum(P.g * (m[1] - n12) for m in reads) - P.d * n12
    return f3, f12


def source(P, Pm, Pp, n3, n12, F, X):
    """The regulator's drive numerator: the strides' product (symmetric under P <-> P+, the head's u_in u_out)
    and the hand's work against its pull at the middle slot (the head's -a F), so that it changes sign."""
    return P.kappa * (Pm[0] * Pp[0] + Pm[1] * Pp[1]) + P.nu * P.T * X * X * (n3 * F[0] + n12 * F[1])


def step_values(P, own, reads, info=None):
    """The event's acts 2 to 4 on a Node-clock's own integers, given the six reads at its moment."""
    n3, n12, b3, b12, r3, r12, X, Xb, rX, dX = own
    W = mean_teeth_of(P.T, Xb, X)
    s = X
    Pm = (W * (n3 - b3) + r3 - mid(W), W * (n12 - b12) + r12 - mid(W))
    f3, f12 = pull(P, n3, n12, reads)
    if P.mutant == 'force_sign':
        f3, f12 = -f3, -f12
    Pp = (Pm[0] + s * f3, Pm[1] + s * f12)
    hold = 2 * P.Tr - P.Dr - SPOKES * P.Rg
    M = sum(P.Rg * m[2] for m in reads)
    Xt, rXn = carry(hold * X - P.Tr * Xb + M, P.Tr, rX)
    q, dXn = carry(source(P, Pm, Pp, n3, n12, (f3, f12), X), P.Td, dX)
    Xn = Xt + q
    Wp = mean_teeth_of(P.T, X, Xn)
    if Wp <= 0:
        raise ValueError('W+ <= 0')
    v3, r3n = carry(Pp[0], Wp, mid(Wp))
    v12, r12n = carry(Pp[1], Wp, mid(Wp))
    if info is not None:
        info.update(W=W, Wp=Wp, s=s, Pm=Pm, Pp=Pp, F=(f3, f12), v=(v3, v12), rho=(r3n - mid(Wp), r12n - mid(Wp)),
                    a=(n3, n12), q=q)
    return (n3 + v3, n12 + v12, n3, n12, r3n, r12n, Xn, X, rXn, dXn)


def unstep_values(P, cur, reads):
    """The event undone: the same acts in the reverse order, each inverted (acts.carry at going -1)."""
    n3p, n12p, n3, n12, r3p, r12p, Xn, X, rXn, dXn = cur
    Wp = mean_teeth_of(P.T, X, Xn)
    s = X
    Pp = (Wp * (n3p - n3) + r3p - mid(Wp), Wp * (n12p - n12) + r12p - mid(Wp))
    f3, f12 = pull(P, n3, n12, reads)
    Pm = (Pp[0] - s * f3, Pp[1] - s * f12)
    going = 1 if P.mutant == 'drive_going' else -1
    q, dX = carry(source(P, Pm, Pp, n3, n12, (f3, f12), X), P.Td, dXn, going)
    Xt = Xn - q
    hold = 2 * P.Tr - P.Dr - SPOKES * P.Rg
    M = sum(P.Rg * m[2] for m in reads)
    Xb, rX = carry(hold * X - P.Tr * Xt + M, P.Tr, rXn, -1)
    W = mean_teeth_of(P.T, Xb, X) if P.mutant != 'undo_W' else Wp
    if W <= 0:
        raise ValueError('W <= 0 in the undo')
    v3, r3 = carry(Pm[0], W, mid(W))
    v12, r12 = carry(Pm[1], W, mid(W))
    return (n3, n12, n3 - v3, n12 - v12, r3, r12, X, Xb, rX, dX)


def event(st, x, P, info=None):
    """One local event at x, at its own now-notch."""
    moment = st.tau[x]
    reads = reads_at(st, x, moment, P)
    new = step_values(P, st.own(x), reads, info)
    st.write(x, new)
    st.tau[x] = moment + P.L(new[7], new[6])
    if info is not None:
        info.update(x=x, moment=moment, reads=reads)
    return moment


def undo(st, x, P):
    """The event at x's before-notch undone."""
    moment = st.sigma(x, P)
    reads = reads_at(st, x, moment - (1 if P.mutant == 'undo_moment' else 0), P)
    old = unstep_values(P, st.own(x), reads)
    st.write(x, old)
    st.tau[x] = moment
    return moment


def due_local(st, x, t_end):
    """The conservative rule: x's now-notch is below the end and no neighbour's now-notch is earlier."""
    t = st.tau[x]
    return t < t_end and all(t <= st.tau[y] for y in st.board.nb[x])


def run_queue(st, P, t_end, rng=None, log=None, info_log=None):
    """The great clock's order: the earliest now-notch next, a tie broken at random (rng) or by index."""
    count = 0
    while True:
        m = min(st.tau)
        if m >= t_end:
            return count
        due = [x for x in range(st.board.N) if st.tau[x] == m]
        x = rng.choice(due) if rng is not None else due[0]
        info = {} if info_log is not None else None
        event(st, x, P, info)
        if log is not None:
            log.append((x, m))
        if info_log is not None:
            info_log.append(info)
        count += 1


def run_local(st, P, t_end, rng):
    """No great clock: any Node-clock whose now-notch is a local minimum, picked at random."""
    count = 0
    while True:
        cand = [x for x in range(st.board.N) if due_local(st, x, t_end)]
        if not cand:
            return count
        event(st, rng.choice(cand), P)
        count += 1


def run_rounds(st, P, t_end):
    """Every local minimum at once, double-buffered: all read the board as it is, then all write."""
    count = 0
    while True:
        cand = [x for x in range(st.board.N) if due_local(st, x, t_end)]
        if not cand:
            return count
        frozen = st.copy()
        for x in cand:
            moment = frozen.tau[x]
            new = step_values(P, frozen.own(x), reads_at(frozen, x, moment, P))
            st.write(x, new)
            st.tau[x] = moment + P.L(new[7], new[6])
        count += len(cand)


def back_queue(st, P, t_start, rng=None):
    """The rewind: the latest before-notch undone first, a tie at random or by index."""
    count = 0
    while True:
        sig = [st.sigma(x, P) for x in range(st.board.N)]
        m = max(sig)
        if m < t_start:
            return count
        due = [x for x in range(st.board.N) if sig[x] == m]
        if P.mutant == 'back_order':        # undone in the forward order's sense: the earliest first
            m = min(s for s in sig if s >= t_start)
            due = [x for x in range(st.board.N) if sig[x] == m]
        undo(st, rng.choice(due) if rng is not None else due[0], P)
        count += 1


def back_local(st, P, t_start, rng):
    """The rewind with no great clock: any Node-clock whose before-notch is a local maximum."""
    count = 0
    while True:
        sig = [st.sigma(x, P) for x in range(st.board.N)]
        cand = [x for x in range(st.board.N)
                if sig[x] >= t_start and all(sig[x] >= sig[y] for y in st.board.nb[x])]
        if not cand:
            return count
        undo(st, rng.choice(cand), P)
        count += 1


def sync_round(st, P):
    """The head's form: every Node-clock reads the start board's nows, then every one writes."""
    frozen = st.copy()
    for x in range(st.board.N):
        reads = [(frozen.n3[y], frozen.n12[y], frozen.X[y]) for y in st.board.nb[x]]
        new = step_values(P, frozen.own(x), reads)
        st.write(x, new)
        st.tau[x] = frozen.tau[x] + P.L(new[7], new[6])


# the 24 and the 48: the signed permutation matrices of determinant +1 (and -1)
def signed_perms():
    import itertools
    mats = []
    for perm in itertools.permutations(range(3)):
        for signs in itertools.product((1, -1), repeat=3):
            M = [[0] * 3 for _ in range(3)]
            for i in range(3):
                M[i][perm[i]] = signs[i]
            det = (M[0][0] * (M[1][1] * M[2][2] - M[1][2] * M[2][1])
                   - M[0][1] * (M[1][0] * M[2][2] - M[1][2] * M[2][0])
                   + M[0][2] * (M[1][0] * M[2][1] - M[1][1] * M[2][0]))
            mats.append((M, det))
    return mats

def charge_terms(info, P):
    """The event's exact charge identity, weighted by 1 / s: the Mesh part and the carry part (Fractions)."""
    a3, a12 = info['a']
    s = info['s']
    mesh = sum(P.g * (a3 * m[1] - a12 * m[0]) for m in info['reads'])   # SUM_j g Im(conj(a) m_j)
    v3, v12 = info['v']
    p3, p12 = info['rho']
    carry_part = Fraction(v3 * p12 - v12 * p3, s)                       # Im(conj(v) rho+) / s
    return mesh, carry_part


def charge_of(st, P):
    """Q_w = SUM_x Im(conj(a) P) / s, the sweep weighted so that the Mesh's two ends' terms are equal."""
    total = Fraction(0)
    for x in range(st.board.N):
        W = mean_teeth_of(P.T, st.Xb[x], st.X[x])
        p3 = W * (st.n3[x] - st.b3[x]) + st.r3[x] - mid(W)
        p12 = W * (st.n12[x] - st.b12[x]) + st.r12[x] - mid(W)
        total += Fraction(st.n3[x] * p12 - st.n12[x] * p3, st.X[x])
    return total

def orbits_of_G(n):
    N = n ** 3
    parent = list(range(N))

    def find(a):
        while parent[a] != a:
            parent[a] = parent[parent[a]]
            a = parent[a]
        return a

    def idx(c):
        return (c[0] % n) + n * ((c[1] % n) + n * (c[2] % n))

    coords = [(i % n, (i // n) % n, i // (n * n)) for i in range(N)]
    for p in coords:
        for M in ROT:
            for v in coords:
                w = [v[k] - p[k] for k in range(3)]
                img = [p[i] + sum(M[i][k] * w[k] for k in range(3)) for i in range(3)]
                a, b = find(idx(v)), find(idx(img))
                if a != b:
                    parent[a] = b
    groups = {}
    for i in range(N):
        groups.setdefault(find(i), []).append(i)
    return coords, list(groups.values()), idx


def two_colouring(n):
    """A split into two classes with no Mesh inside a class, by breadth-first search, or None."""
    N = n ** 3
    coords = [(i % n, (i // n) % n, i // (n * n)) for i in range(N)]

    def idx(c):
        return (c[0] % n) + n * ((c[1] % n) + n * (c[2] % n))
    colour = [None] * N
    colour[0] = 0
    queue = [0]
    while queue:
        x = queue.pop()
        c = coords[x]
        for axis in range(3):
            for side in (1, -1):
                d = list(c)
                d[axis] += side
                y = idx(d)
                if colour[y] is None:
                    colour[y] = 1 - colour[x]
                    queue.append(y)
                elif colour[y] == colour[x]:
                    return None
    return colour
