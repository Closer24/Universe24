## 1. The gear, the step and the turnover (the definitions)

- **The state** of a driven gear: (a-, a, r), the notch before, the notch now, the fine tooth, at its teeth count W >= 1,
  with 0 <= r < W. mid(n) = n div 2, Rule3's carry on the Spoke's two sides (acts.mid).
- **The stride** read at a mid tooth m: P = W (a - a-) + (r - m(W)). By Rule3's uniqueness the pair (a - a-, r) and P
  determine each other at fixed W: a - a- = (P + m) div W and r = (P + m) mod W. So the state is (a, P).
- **The step S** (the matter's half of the one formula, cut 0's letter, DAVID-TENSOR24-THE-ONE-FORMULA.md):
  W+ (a+ - a) + (r+ - m(W+)) = W (a - a-) + (r - m(W)) + k, with the kick
  k = s [SUM_j g_j (m_j - a) - D a + q_P] + T s q_K read at the now notch and time-even. One carry:
  a+ - a = (P + k + m(W+)) div W+, r+ the remainder. With q_V(p) = (p + m(V)) div V:
  S(a, P) = (a + q_W+(P + k(a)), P + k(a)).
- **The turnover T** (law 4; ALGEBRA.md line 1602: "it ends the tick at the state it started from with every gear's two
  notches exchanged and every fine tooth mirrored about its mid tooth, the one mirror of **The cube's symmetry** ...,
  the step's output discarded"). A turnover that exchanges the slots is T(a, P) = (a - q_W(P), phi(P)): its new now is
  the old before. The head's mirror (acts.mirror) is r -> (mid + mid - r) mod W.
- **The retrace.** Law 10's circle runs forward to the top, turns, and runs back by the same act. One step of the run
  back is S T S = T: one step, the turnover, one step land on the turned start. Where T T = 1 this is T S T = S^-1,
  the mathematician's condition. **T S T = S^-1 alone is not enough** (CHECKED): Animate's carried mirror with the
  carry in the before slot satisfies it at every state (0 of 41,160) and still misses the run back at 1,960 (its
  T T moves both notches by one at the tooth 0). The law to state is S T S = T with T T = 1.

## 2. The formula in the three operations (protocol step 1)

**FRAME**, for every driven gear, the frame f in {0, 1}:

    m_f(W) = mid(W) + f (W - 1 - mid(W) - mid(W))                   the frame's mid tooth
    P      = W (a - a-) + (r - m_f(W))                               the stride, read in the frame
    P+     = P + k                                                   the kick, as the one formula has it
    a+ - a, r+  = Rule3 of P+ + m_f(W+) at the teeth W+               one carry, 0 <= r+ < W+
    turnover:  a <-> a-,  r -> W - 1 - r,  f -> 1 - f               the flip, the frame toggled

- Clock words: the frame is the gear's count of reversals mod 2, time's and the sign's alike: acts.flip's own letter,
  "flipped to teeth - 1 - r once for every reversal of its gear (time's reverse, the sign's negation), two reversals
  leaving it". At a turnover the gears K leaves turn once (f toggles); the gears K negates (a hand's twelve gear) turn
  twice (r and f unchanged). For the turnover alone the frame of the gears K leaves is the Node-clock's ratchet
  remainder (line 1602: "complemented at the swap like every remainder, so that the remainder is the hand's frame, 1 at
  a hand time-reversed an odd number of times"), and 0 on the gears K negates: no new state.
- At an odd W, W - 1 - mid(W) - mid(W) = 0: m_1 = m_0 = mid, the frame is not read, and the flip is the one mirror.
  At an even W, m_1(W) = mid(W) - 1: the reversed frame rounds a tie down where the forward frame rounds it up.
- Numbers: 0, 1 and the Spoke's two sides (in mid). No branch, no parity test: f multiplies the count's own
  W - 1 - mid(W) - mid(W). Every remainder stays in Rule3's range.

**DOUBLED**, FRAME's frame-free spelling, for every driven gear:

    P2     = (W + W)(a - a-) + r2 - W,   0 <= r2 < W + W              the fine tooth at the doubled count
    P2+    = P2 + k + k
    a+ - a, r2+ = Rule3 of P2+ + W+ at the teeth W+ + W+              mid(2 W) = W, exact at every W
    turnover:  a <-> a-,  r2 -> W + W - 1 - r2                       the flip at the doubled count
    the stride read:  P = (P2 + 1) div 2                             Rule3 on the two sides

- The frame rides in P2's parity (f = P2 mod 2), per gear. The head's state is r2 = 2 r + (W - mid(W) - mid(W)).
- The regulator (its own constant teeth) and every drive (its constant drive count) keep their one carry; their
  turnover is the flip (Proposition E).

## 3. The proofs (protocol step 2)

**Lemma 1 (Rule3's one reflection). PROVED.** For every integer u and W >= 1, if u = q W + r with 0 <= r < W, then
W - 1 - u = (-q) W + (W - 1 - r) with 0 <= W - 1 - r < W; by the uniqueness of Rule3's pair, carry(W - 1 - u) =
(-q, W - 1 - r). (It is acts.carry at -1's own letter.) Hence, at a fixed mid tooth m, q_W(c - p) = -q_W(p) for every
p if and only if c = W - 1 - 2 m: the carry's reflection centre is the stride (W - 1 - 2 m) / 2, which is the integer
0 at m = mid(W) only at an odd W, and -1/2 at an even W.

**Lemma 2 (no odd rounding in Rule3's range at an even count). PROVED.** Let p -> (q(p), e(p)) be any bijection of the
integers onto Z x [0, W) (every carry with its remainder in [0, W) is one: each quotient has exactly W strides). If q
were odd, q(-p) = -q(p), then q(0) = 0 and the fibre q^-1(0) would be symmetric under p -> -p and contain 0, so its size
would be odd; but it has W elements. So at an even W no such q is odd: the exact reversal P -> -P cannot be a
symmetry of any carry in Rule3's range, and an exact form must carry one more bit (the frame).

**Theorem A (the retrace and its one solution). PROVED.** Let a turnover exchange the two slots and send the stride P,
read in the frame f, to phi(P), read in the frame f'. Then S T S = T holds for every time-even kick and every pair of
counts W, W+ of either parity if and only if phi(P) = c - P for one constant c and m_f(V) + m_f'(V) = V - 1 - c at every
count V.
*Proof.* From x = (a, P): S x = (a+, P+), P+ = P + k(a), a+ = a + q^f_W+(P+). The turnover: T S x =
(a+ - q^f_W+(P+), phi(P+)) = (a, phi(P+)) in the frame f'. The step: S T S x = (a + q^f'_W(phi(P+) + k(a)),
phi(P+) + k(a)). And T x = (a - q^f_W(P), phi(P)). Equal for all P and k:
(1) phi(P + k) + k = phi(P) for all P, k, so phi(P) + P is a constant c;
(2) q^f'_W(c - P) = -q^f_W(P) for all P, which by Lemma 1 (u = P + m_f(W)) holds if and only if
c + m_f'(W) = W - 1 - m_f(W). Substituting back shows both are sufficient. QED
- **The solution.** With c = 0 (the stride reversed exactly, a gear at rest kept at rest): m_f'(V) = V - 1 - m_f(V). With
  m_0 = mid (the head's) this is FRAME with f' = 1 - f; the remainder's map is then r -> W - 1 - r (the flip):
  W (a- - a) + r' - m_1 = -P gives r' = m_0 + m_1 - r = W - 1 - r, always in [0, W).
- **One mid tooth for both directions cannot serve both parities.** f' = f and m_f = m require V - 1 - 2 m(V) = c at
  every V; its left side has the parity of V - 1, so no c serves both parities. At one parity it can: c = -1 at every
  even count (the flip with the head's mid, which then reads -P - 1), c = 0 at every odd count (the one mirror).
- **The head's one mirror** is no reflection: it reads -P where r > 0 and -P - W where r = 0 at an even W, so phi is not
  of the form c - P and (1) fails there.

**Corollaries. PROVED.** (a) FRAME's turnover is an involution: T T (a, P) = (a - q^f(P) - q^(1-f)(-P), P) = (a, P),
since q^(1-f)(-P) = -q^f(P) by (2). (b) The stride is read reversed exactly, P -> -P, and a gear born at its frame's
mid tooth reads 0 and stays at rest. (c) In the frame 0 FRAME is the head's step, bit for bit. (d) With the weak top
symmetric in the time gear's two outer notches (law 4), the act M (the turnover at a top, else the step) satisfies
M T M = T, so M^n (T z_n) = T z_0: the whole run back returns the turned start through every turnover between. (For a
state z not at a top, T S z is not at a top, its triple being z's reversed; at a top, M T M z = M T T z = M z = T z.)

**Theorem B (DOUBLED is FRAME). PROVED.** The map (a-, a, r, f) -> (a-, a, r2) with r2 = 2 r + c for f = 0 and
r2 = 2 r + 1 - c for f = 1, c = W - mid(W) - mid(W), is a bijection onto [0, 2 W) (the two frames are r2's two parity
classes). It gives P2 = 2 P_0 in the frame 0 and P2 = 2 P_1 - 1 in the frame 1, so (P2 + 1) div 2 = P_f. The carry:
in the frame 0, (2 P + W+) div 2 W+ = (P + mid(W+)) div W+ at both parities of W+ (at an odd W+, 2 P + W+ is odd and
adding a half never crosses a multiple); in the frame 1, (2 P - 1 + W+) div 2 W+ = (P + m_1(W+)) div W+ alike. The flip
at 2 W sends P2 to -P2 - 1: 2 P_0 goes to 2 (-P_0) - 1, the frame 1's code of -P_0, and 2 P_1 - 1 to 2 (-P_1), the frame
0's code of -P_1. That is FRAME's turnover. QED

**Theorem C (Animate's (i) and (ii) together). PROVED.** Let the remainder take the values [0, 2 mid(W)] (the tooth w
kept at an even W, DAVID-THE-ONE-MIRROR.md's letter: "the tooth w stands only as the mirror's image of 0"), the
rounding send an exact tie to the even quotient, and the turnover be r -> 2 mid(W) - r with no mod. The rounding is

names), the step retraces but the before slot stands one notch off the notch before at those ties.

**Theorem D (the 24 and the 48). PROVED.** A turn g carries a vector gear to sigma times a gear at g x, with a kick odd
under the sign (the kick is linear in the notches and covariant). A negated gear keeps its slots: N(a, P) =
(-a, phi(P)). S N = N S for every such kick at every W -> W+ gives, as in Theorem A, phi(P) = c - P and
m_f + m_f' = V - 1 - c: the negation is the flip with the frame toggled, per gear. At one parity the law's complement

DOUBLED carries each gear's frame in its own tooth, so it holds the 48 with no shared bit; FRAME needs a frame per

**Proposition E (the gears that need no frame). PROVED.**
(E1) The twelve gear, which K negates at the turnover: (a-, a, r) -> (-a, -a-, r) sends P to +P with no rounding read,
so for a kick odd under the sign the run back lands on (-a, -a-, r) at every count.
(E2) The regulator at its own constant teeth (Rule3's flux form T a+ + r' = 2 T a - T a- + F(a) + r): the flip is exact

"""The forms of the turnover's mirror and of the step's rounding on one driven gear. Exact integers only.

A driven gear's state is (b, a, r): the notch before, the notch now, the fine tooth, held at the teeth count W.
The matter's half of the one formula (cut 0's letter, DAVID-TENSOR24-THE-ONE-FORMULA.md on toys-5):

    W+ (a+ - a) + (r+ - m(W+)) = W (a - a-) + (r - m(W)) + k,     k = s F(a) + K (the kick, time-even)

that is P = W (a - b) + r - m(W), P+ = P + k, and one carry a+ = a + (P+ + m(W+)) div W+, r+ = (P+ + m(W+)) mod W+.
The turnover T exchanges the two slots and mirrors the fine tooth. Only +, *, and Rule3's carry (divmod) are used;
mid(n) = n div 2 is Rule3's carry on the Spoke's two sides.

Each form has: name, step(st, W, Wp, k), T(st, W), P(st, W) (the stride as the form reads it), states(W, R)
(its whole state space on the notches -R..R), born(W) (the gear born at rest), and an `encode` from the head's state.
The forms:
  HEAD      the head: the one mirror r -> (mid + mid - r) mod W, its carry dropped; the rounding (P + mid) div W
  FLIP      the flip r -> W - 1 - r (Rule3's own reflection, acts.carry at -1); the rounding of the head
  CBEF      Animate's (i): the mirror's carry c = (mid + mid - r) div W kept in the stride, in the before slot
  CNOW      Animate's (i): the same, the carry in the now slot
  TDROP     Animate's (ii) alone in the head's encoding: the tie sent to the even quotient, the remainder taken mod W
  TKEEP     Animate's (ii) alone with its remainder kept in [0, W]; the head's mirror (mod W) at the turnover
  CLOSED    (i) and (ii) together in their closed letter: the remainder in [0, 2 mid], the mirror r -> 2 mid - r
            with no mod (DAVID-THE-ONE-MIRROR.md's letter: "the tooth w stands only as the mirror's image of 0"),
            the tie sent to the even quotient
  CTIE      (i) and (ii) together in Rule3's range [0, W): the carry kept in the slot the even quotient names
  FRAME     proposed: the flip, and the mid tooth of the gear's frame f (its reversals mod 2):
            m_0(W) = mid(W), m_1(W) = W - 1 - mid(W); the turnover toggles f
  DOUBLED   proposed, FRAME's frame-free encoding: the fine tooth at the doubled count 2 W (mid tooth W, exact at
            every W), the flip at 2 W, the stride read as P = (P2 + 1) div 2
"""

from __future__ import annotations

SIDES = 2  # the two sides of a Spoke: the one count the halving reads


def mid(n: int) -> int:
    """The mid tooth, Rule3's carry on the two sides."""
    return divmod(n, SIDES)[0]


def carry(u: int, w: int) -> tuple[int, int]:
    """Rule3: u = q w + r', 0 <= r' < w."""
    return divmod(u, w)


def tie_even(u: int, w: int) -> tuple[int, int]:
    """Animate's (ii): the carry of u = P + mid(w), an exact tie (2 P = (2 k + 1) w) sent to the even quotient.
    Written in the three operations: q, s = carry(u, w); the tie is (2 u - 2 mid(w) + w) mod 2 w == 0, which no odd
    w meets; the indicator [n == 0] for 0 <= n < d is 1 - (n + d - 1) div d. The remainder reaches w at a tie whose
    floor quotient is odd: it leaves Rule3's range [0, w)."""
    q, s = carry(u, w)
    p = u - mid(w)
    n = (p + p + w) % (w + w)
    tie = 1 - (n + w + w - 1) // (w + w)
    odd = q % SIDES
    return q - tie * odd, s + w * tie * odd


def tie_up(u: int, w: int) -> tuple[int, int]:
    return carry(u, w)


def _tie(u: int, w: int) -> int:
    p = u - mid(w)
    n = (p + p + w) % (w + w)
    return 1 - (n + w + w - 1) // (w + w)


def tie_odd(u: int, w: int) -> tuple[int, int]:
    """A tie sent to the odd quotient (another odd rounding)."""
    q, s = carry(u, w)
    t = _tie(u, w) * (1 - q % SIDES)
    return q - t, s + w * t


def tie_away(u: int, w: int) -> tuple[int, int]:
    """A tie sent away from zero (another odd rounding): down where the stride is negative."""
    q, s = carry(u, w)
    p = u - mid(w)
    neg = -(p // (p * p + 1))  # [p < 0] in the three operations (the mathematician's sign test)
    t = _tie(u, w) * neg
    return q - t, s + w * t


class Form:
    name = ""
    frame = False

    def born(self, W: int) -> int:
        return mid(W)

    def states(self, W: int, R: int):
        for b in range(-R, R + 1):
            for a in range(-R, R + 1):
                for r in range(W):
                    yield (b, a, r)

    def encode(self, st, W):
        """From the head's state (b, a, r), r in [0, W)."""
        return st

    def P(self, st, W):
        b, a, r = st[:3]
        return W * (a - b) + r - mid(W)


class Head(Form):
    name = "HEAD"

    def step(self, st, W, Wp, k):
        b, a, r = st
        q, rp = carry(W * (a - b) + r - mid(W) + k + mid(Wp), Wp)
        return (a, a + q, rp)

    def T(self, st, W):
        b, a, r = st
        return (a, b, carry(mid(W) + mid(W) - r, W)[1])


class Flip(Head):
    name = "FLIP"

    def T(self, st, W):
        b, a, r = st
        return (a, b, W - 1 - r)


class CarryBefore(Head):
    name = "CBEF"

    def T(self, st, W):
        b, a, r = st
        c, r2 = carry(mid(W) + mid(W) - r, W)
        return (a - c, b, r2)


class CarryNow(Head):
    name = "CNOW"

    def T(self, st, W):
        b, a, r = st
        c, r2 = carry(mid(W) + mid(W) - r, W)
        return (a, b + c, r2)


class TieDrop(Head):
    name = "TDROP"

    def step(self, st, W, Wp, k):
        b, a, r = st
        q, rp = tie_even(W * (a - b) + r - mid(W) + k + mid(Wp), Wp)
        return (a, a + q, rp % Wp)


class TieKeep(Head):
    name = "TKEEP"

    def states(self, W, R):
        for b in range(-R, R + 1):
            for a in range(-R, R + 1):
                for r in range(2 * mid(W) + 1):
                    st = (b, a, r)
                    if self.canonical(st, W):
                        yield st

    tie = staticmethod(tie_even)

    def canonical(self, st, W):
        b, a, r = st
        return self.tie(W * (a - b) + r, W) == (a - b, r)

    def step(self, st, W, Wp, k):
        b, a, r = st
        q, rp = self.tie(W * (a - b) + r - mid(W) + k + mid(Wp), Wp)
        return (a, a + q, rp)

    def encode(self, st, W):
        b, a, r = st
        q, rr = self.tie(W * (a - b) + r, W)
        return (a - q, a, rr)


class Closed(TieKeep):
    name = "CLOSED"

    def T(self, st, W):
        b, a, r = st
        return (a, b, mid(W) + mid(W) - r)

class CarryTie(Head):
    """(i) and (ii) in Rule3's range: the state is the head's (r in [0, W)), read by the plain decoding; the
    position is the now slot; the step moves it by the even-tie quotient; the turnover puts the mirror's carry in
    the slot that the even quotient names."""

    name = "CTIE"

    def step(self, st, W, Wp, k):
        b, a, r = st
        p = W * (a - b) + r - mid(W) + k
        q, _ = tie_even(p + mid(Wp), Wp)
        a1 = a + q
        qf, rp = carry(p + mid(Wp), Wp)
        return (a1 - qf, a1, rp)

    def T(self, st, W):
        b, a, r = st
        p = W * (a - b) + r - mid(W)
        q, _ = tie_even(p + mid(W), W)
        now = a - q
        qf, r2 = carry(-p + mid(W), W)
        return (now - qf, now, r2)

        b, a, r, f = st
        return (a, b, W - 1 - r, 1 - f)

def time_step(t, Tx, Dx, Xc):
    xb, x, rx = t
    q, r = divmod(Tx * (x + x - xb) + Dx * (Xc - x) + rx, Tx)
    return (x, q, r)


def time_T(t, Tx):
    xb, x, rx = t
    return (x, xb, Tx - 1 - rx)


def act(form, z, w, Tx, Dx, Xc, g, D, c):
    t, gears = z
    t2 = time_step(t, Tx, Dx, Xc)
    x0, x1, x2 = t[0], t[1], t2[1]
    W = w * (x0 + x1)
    if x0 <= x1 and x2 <= x1 and (x0 < x1 or x2 < x1):
        return (time_T(t, Tx), tuple(form.T(st, W) for st in gears)), True
    Wp = w * (x1 + x2)
    nows = [st[1] for st in gears]
    out = []
    for i, st in enumerate(gears):
        k = x1 * (g * (nows[i - 1] + nows[(i + 1) % N] - nows[i] - nows[i]) - D * nows[i] + c)
        out.append(form.step(st, W, Wp, k))

def turned(form, z, w, Tx):

class Form:
    def __init__(self, name):
        self.name = name

    def m(self, W, f):
        return mid(W)

    def P(self, st, W):
        return W * (st[1] - st[0]) + st[2] - self.m(W, st[3] if len(st) > 3 else 0)

    def step(self, st, W, Wp, k):
        b, a, r = st[:3]
        f = st[3] if len(st) > 3 else 0
        q, rp = carry(W * (a - b) + r - self.m(W, f) + k + self.m(Wp, f), Wp)
        return (a, a + q, rp) + st[3:]

    def neg(self, st, W):
        raise NotImplementedError

    def make(self, b, a, r, W):
        return (b, a, r)


class Head(Form):

class Flip(Form):

class Frame(Form):

    def neg(self, st, W):
        b, a, r, f = st
        return (-b, -a, W - 1 - r, 1 - f)

    def make(self, b, a, r, W):
        return (b, a, r, 0)

        return (-b, -a, W + W - 1 - r2)

    def make(self, b, a, r, W):
        return (b, a, r + r + (W - mid(W) - mid(W)))

def turn_all(c):
    held = [[g.copy() for g in t] for t in c.trains()]
    c.reverse(np.ones(c.size, dtype=bool), held)


def run(x):

    y.tick()
    turned = y.turned_over.copy()
    turn_all(y)
    y.tick()
    z = copy.deepcopy(x)

    driven, regulator = {}, 0
    for k, (ry, rz) in enumerate(zip(y.trains_, z.trains_)):
