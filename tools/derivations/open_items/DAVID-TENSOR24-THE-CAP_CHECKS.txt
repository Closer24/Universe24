## 1. The words

- **The twin pair** psi = (u, d) at a Node-clock, two Gaussian numbers: the up hand and the down hand.
- **The Spoke's two senses** P_a^+- = (1 +- sigma_a)/2, the projectors of the twins' turn about axis a.
- **The axis sub-act** W_a = P_a^+ T_+a + P_a^- T_-a, where (T_+a psi)(x) = psi(x - e_a). The up sense moves along +a and the down sense along -a.
- **The opposite helicity's sub-act** W~_a = P_a^- T_+a + P_a^+ T_-a.
- **The Weyl tick** U_L = W_z W_y W_x, with W_x first. Its symbol is V(k) = exp(-i kz sigma_z) exp(-i ky sigma_y) exp(-i kx sigma_x).
- **The phase reversal** T = i sigma_y K (draft E).
- **The Dirac pair** (psi_L, psi_R): the family's field beside its phase-reversed field. Its tick is U = M (U_L + U_R), with U_R = sigma_y conj(U_L) sigma_y.
- **The turn on den's circle** M = [[pinion, -i s], [-i s, pinion]] / den, acting on (L, R) at each spin. Here s = sine_rim(pinion, den) is the engine's integer sine, and pinion^2 + s^2 = den^2 (MS-S2). Its cosine and sine are c = pinion/den and s/den.
- **The tensor** rho = R / lam, with R Hermitian of Gaussian integers and lam > 0 an integer (the scale). Its block at Node-clock x is rho_xx, an m x m matrix (m = 2 for the twins, 4 for the Dirac pair).
- **The free size** of a newcomer chi is chi^dagger (1 - rho) chi; F = lam times it.

## 2. The clock's first-order step (part A)

### 2.1 The formula in the three operations

At every Node-clock x, with psi- = psi(x - e_a) and psi+ = psi(x + e_a), the sub-acts are these. In the exact form the halves and den stay in the scale (2.3).
- **z:** u' = u-, d' = d+. Pure moves, with no arithmetic.
- **x:** 2u' = (u- + d-) + (u+ - d+), 2d' = (u- + d-) - (u+ - d+).
- **y:** 2u' = (u- - i d-) + (u+ + i d+), 2d' = (i u- + d-) + (d+ - i u+).
- **The turn on den's circle** (the Dirac pair), at each spin: den L' = pinion L - i s R, den R' = -i s L + pinion R.
- **The R field** takes the same sub-acts with the senses exchanged.

The numbers are 1, i, the 2 of a Spoke's two sides, and the calibre's pinion, s and den. There is no root, no angle and no table. The tick is three sub-acts of one Mesh each. The whole tick reaches the eight corners (three Meshes): each hand reaches 4 of them, the up hand the +z ones and the down hand the -z ones (c5: per row {4}, per Node-clock {8}). It is Bialynicki-Birula's automaton (his eq. 10, with q_+- = (1 +- i)/4 and rank-one P_i) up to his conventions: his symbol, eq. 27, is ours at -k (c1).

**The junction form, with the 24's lifts as Gaussian units:**
- W_a = Q_a S_a Q_a^dagger, where S_a is the integer shift (up +a, down -a) and Q_a maps sigma_z to sigma_a:
  - Q_x = [[1, 1], [1, -1]] / (1 - i), the edge half turn's lift;
  - Q_y = [[1, 1], [i, -i]] / (1 - i);
  - Q_z = 1.
- The x-to-y junction is Q_y^dagger Q_x = [[1, i], [i, 1]] / (1 + i).
- So a tick holds three Rule3 divisions by the Gaussian prime above 2, one per junction, and one by den for the mass. This is Arrighi, Forets and Nesme's factorisation (their W_epsilon: the Hadamard and F = R_{pi/2} H between partial shifts).
- The mass cannot come from the 24: their lifts turn by multiples of pi/4 and pi/3. It comes from den's circle, as the engine's pairs do.

### 2.2 The proofs

- **P1, unitarity.**

  - M^dagger M = (pinion^2 + s^2)/den^2 = 1.
  - U_L, U_R and M (U_L + U_R) are products of unitaries.

    - the operators on rings of 8, 12 and 16 and on the tori 3^3 and 4^3, 9 of 9;

- **P2, the clock picture.** W_a(k) = P^+ e^{-ik} + P^- e^{ik} = cos k - i sigma_a sin k = exp(-i k sigma_a). Each sub-act is a turn of the twin pair about a by the Spoke's phase, so each tick is a rotation of the state before, in every momentum. PROVED. CHECKED (c1: 300 of 300).
- **P3, the junctions.** Q_a sigma_z Q_a^dagger = sigma_a gives Q_a P_z Q_a^dagger = P_a, and so W_a = Q_a S_a Q_a^dagger.

- **P4, the coin as a Cayley form.** For any Hermitian A, C = (1 - iA)(1 + iA)^-1 is unitary.

## 3. The family's tensor (part B)

### 3.1 The formula in the three operations

- **The step:** R <- (D U) R (D U)^dagger and lam <- lam N(D): sums of products on the rows, and the same, conjugated, on the columns.
- **The lay, e = -1:**
  - F = lam chi^dagger chi - chi^dagger R chi.
  - Where F = 0 it is refused (Rule3's sign test).
  - Otherwise v = lam chi - R chi, R <- F R + v v^dagger and lam <- lam F.
  - The division by the free size is deferred into the scale, with no root.
- **The lay, e = +1:** R <- (chi^dagger chi) R + lam chi chi^dagger and lam <- lam (chi^dagger chi).
- **The click's reads at x:**
  - the count, Tr R_xx / lam;
  - the pair, det R_xx / lam^2;
  - a newcomer s's free size, (lam s^dagger s - s^dagger R_xx s) / lam.
  - Each is a Rule3 division by the scale.
- **The pitch:** the gcd of R and lam is removed (Euclid's carry, rule3.pitch). The algebra of P15 to P20 does not depend on it.

### 3.2 The proofs

- **P15, the step keeps the spectrum.** (U rho U^dagger)^2 = U rho^2 U^dagger, and every Tr rho^j is kept. A projector stays a projector with its trace. PROVED.

"""Exact helpers for the cap probes: Gaussian numbers as (re, im) pairs of int or Fraction, small dense matrices,
sparse board operators, the clock's split step (the Spoke's two senses), the 24's lifts, and the scaled tensor.

No float anywhere. Every division is a Fraction or an exact integer division that is checked.
"""

from __future__ import annotations

import random
from fractions import Fraction as Fr
from itertools import product
from math import gcd

# ---------------------------------------------------------------- Gaussian numbers

ZERO, ONE, I = (0, 0), (1, 0), (0, 1)


def ga(a, b):
    return (a[0] + b[0], a[1] + b[1])


def gs(a, b):
    return (a[0] - b[0], a[1] - b[1])


def gm(a, b):
    return (a[0] * b[0] - a[1] * b[1], a[0] * b[1] + a[1] * b[0])


def gc(a):
    return (a[0], -a[1])


def gn(a):
    return a[0] * a[0] + a[1] * a[1]


def gk(k, a):
    return (k * a[0], k * a[1])


def gdiv(a, b):
    """a / b exactly, Fractions (b != 0)."""
    n = gn(b)
    p = gm(a, gc(b))
    return (Fr(p[0], n), Fr(p[1], n))


def fr(a):
    return (Fr(a[0]), Fr(a[1]))


# ---------------------------------------------------------------- dense matrices of Gaussian numbers


def mzero(r, c=None):
    c = r if c is None else c
    return [[ZERO] * c for _ in range(r)]


def meye(n):
    return [[ONE if i == j else ZERO for j in range(n)] for i in range(n)]


def mmul(A, B):
    n, m, p = len(A), len(B), len(B[0])
    out = []
    for i in range(n):
        row = []
        Ai = A[i]
        for j in range(p):
            re = im = 0
            for k in range(m):
                a, b = Ai[k], B[k][j]
                re += a[0] * b[0] - a[1] * b[1]
                im += a[0] * b[1] + a[1] * b[0]
            row.append((re, im))
        out.append(row)
    return out


def madj(A):
    return [[gc(A[j][i]) for j in range(len(A))] for i in range(len(A[0]))]


def madd(A, B):
    return [[ga(a, b) for a, b in zip(ra, rb)] for ra, rb in zip(A, B)]


def msub(A, B):
    return [[gs(a, b) for a, b in zip(ra, rb)] for ra, rb in zip(A, B)]


def mscale(k, A):
    """k a Gaussian number."""
    return [[gm(k, a) for a in row] for row in A]


def meq(A, B):
    return all(a[0] == b[0] and a[1] == b[1] for ra, rb in zip(A, B) for a, b in zip(ra, rb))


def mtr(A):
    t = ZERO
    for i in range(len(A)):
        t = ga(t, A[i][i])
    return t


def kron(A, B):
    return [[gm(A[i][j], B[k][l]) for j in range(len(A[0])) for l in range(len(B[0]))] for i in range(len(A)) for k in range(len(B))]


def mfr(A):
    return [[fr(a) for a in row] for row in A]


def charpoly(A):
    """Coefficients [1, c1, ..., cn] of det(x I - A) by Faddeev-LeVerrier, exact (Fractions)."""
    n = len(A)
    A = mfr(A)
    coeffs = [(Fr(1), Fr(0))]
    M = mzero(n)
    for k in range(1, n + 1):
        AM = mmul(A, M)
        M = [[ga(AM[i][j], coeffs[-1] if i == j else ZERO) for j in range(n)] for i in range(n)]
        tr = mtr(mmul(A, M))
        coeffs.append((Fr(-tr[0], k), Fr(-tr[1], k)))
    return coeffs


# ---------------------------------------------------------------- Pauli matrices and the Spoke's two senses

S0 = [[ONE, ZERO], [ZERO, ONE]]
SX = [[ZERO, ONE], [ONE, ZERO]]
SY = [[ZERO, (0, -1)], [I, ZERO]]
SZ = [[ONE, ZERO], [ZERO, (-1, 0)]]
SIG = [SX, SY, SZ]
HALF = (Fr(1, 2), Fr(0))


def proj(a, sense):
    """P_a^sense = (1 + sense sigma_a) / 2, sense = +1 or -1."""
    return mscale(HALF, madd(S0, mscale((sense, 0), SIG[a])))


def rotation_of(u):
    """The 3x3 matrix R with u sigma_a u^dagger = SUM_b R_ba sigma_b (exact; u unitary up to a phase)."""
    ud = madj(u)
    norm = mtr(mmul(u, ud))  # 2 |phase|^2
    R = [[None] * 3 for _ in range(3)]
    for a in range(3):
        img = mmul(mmul(u, SIG[a]), ud)
        for b in range(3):
            t = mtr(mmul(SIG[b], img))
            v = gdiv(t, norm)
            assert v[1] == 0
            R[b][a] = v[0]
    return R


def the_24():
    """The cube's 24 turns as (R, u): u a Gaussian lift up to a phase, generated by the quarter turn about z,
    diag(1, i), and the edge half turn (1/(1 - i)) [[1, 1], [1, -1]] (the Hadamard, a lift of the turn by pi about x + z)."""
    uz = [[fr(ONE), fr(ZERO)], [fr(ZERO), fr(I)]]
    q = gdiv(ONE, (1, -1))
    h = [[q, q], [q, gk(-1, q)]]
    found = {}
    frontier = [mfr(meye(2))]
    while frontier:
        nxt = []
        for u in frontier:
            for g in (uz, h):
                w = mmul(g, u)
                R = rotation_of(w)
                key = tuple(tuple(r) for r in R)
                if key not in found:
                    found[key] = w
                    nxt.append(w)
        frontier = nxt
    return [(list(map(list, k)), u) for k, u in found.items()]

def pyth_phases(count, rng, top=40):
    """zeta = e^{ik} = (m + i n)^2 / (m^2 + n^2) as a Fraction pair, with cos k and sin k rational."""
    out = []
    while len(out) < count:
        m, n = rng.randint(-top, top), rng.randint(-top, top)
        if m == 0 and n == 0:
            continue
        z = gm((m, n), (m, n))
        d = m * m + n * n
        out.append((Fr(z[0], d), Fr(z[1], d)))
    return out


# ---------------------------------------------------------------- boards and sparse operators


class Board:
    """A torus of side L in d dimensions with m components per Node-clock; index = site * m + component."""

    def __init__(self, L, d, m):
        self.L, self.d, self.m = L, d, m
        self.sites = list(product(range(L), repeat=d))
        self.index = {s: i for i, s in enumerate(self.sites)}
        self.V = len(self.sites)
        self.n = self.V * m

    def step(self, s, axis, e):
        t = list(s)
        t[axis] = (t[axis] + e) % self.L
        return tuple(t)


def sp_from_blocks(board, blocks):
    """A sparse operator from a list of (displacement d, m x m matrix A): (U psi)(x) = SUM A psi(x - d)."""
    U = [dict() for _ in range(board.n)]
    m = board.m
    for s in board.sites:
        x = board.index[s]
        for disp, A in blocks:
            t = tuple((s[a] - disp[a]) % board.L for a in range(board.d))
            y = board.index[t]
            for c in range(m):
                for c2 in range(m):
                    v = A[c][c2]
                    if v[0] or v[1]:
                        key = y * m + c2
                        old = U[x * m + c].get(key, ZERO)
                        U[x * m + c][key] = ga(old, v)
    return [{k: v for k, v in row.items() if v[0] or v[1]} for row in U]


def sp_mul(A, B):
    out = []
    for row in A:
        acc = {}
        for k, a in row.items():
            for j, b in B[k].items():
                acc[j] = ga(acc.get(j, ZERO), gm(a, b))
        out.append({j: v for j, v in acc.items() if v[0] or v[1]})
    return out


def sp_adj(A):
    n = len(A)
    out = [dict() for _ in range(n)]
    for i, row in enumerate(A):
        for j, v in row.items():
            out[j][i] = gc(v)
    return out


def sp_eq(A, B):
    return all(ra == rb for ra, rb in zip(A, B))


def sp_scale(k, A):
    return [{j: gm(k, v) for j, v in row.items()} for row in A]


def sp_is_identity(A, lam=ONE):
    return all(row == ({i: lam} if (lam[0] or lam[1]) else {}) for i, row in enumerate(A))


def sp_apply(A, v):
    out = []
    for row in A:
        re = im = 0
        for j, a in row.items():
            b = v[j]
            re += a[0] * b[0] - a[1] * b[1]
            im += a[0] * b[1] + a[1] * b[0]
        out.append((re, im))
    return out

def axis_step(board, axis, senses=(1, -1)):

def dirac_step(board3, pinion, s, den):

# ---------------------------------------------------------------- the scaled tensor rho = R / lam (Gaussian integers)


class Tensor:
    """rho = R / lam with R a Hermitian matrix of Gaussian integers and lam a positive integer."""

    def __init__(self, n):
        self.n = n
        self.R = mzero(n)
        self.lam = 1

    def copy(self):
        t = Tensor(self.n)
        t.R = [row[:] for row in self.R]
        t.lam = self.lam
        return t

    def reduce(self):
        g = self.lam
        for row in self.R:
            for v in row:
                g = gcd(g, v[0])
                g = gcd(g, v[1])
                if g == 1:
                    return
        if g > 1:
            self.lam //= g
            self.R = [[(v[0] // g, v[1] // g) for v in row] for row in self.R]

    def matvec(self, v):
        out = []
        for row in self.R:
            re = im = 0
            for a, b in zip(row, v):
                re += a[0] * b[0] - a[1] * b[1]
                im += a[0] * b[1] + a[1] * b[0]
            out.append((re, im))
        return out

    def free_size(self, chi):
        """F = lam |chi|^2 - chi^dagger R chi: lam times the Pauli free size chi^dagger (1 - rho) chi."""
        Rc = self.matvec(chi)
        q = ZERO
        for a, b in zip(chi, Rc):
            q = ga(q, gm(gc(a), b))
        assert q[1] == 0
        return self.lam * sum(gn(a) for a in chi) - q[0], Rc

    def lay(self, chi, e):
        """The generic lay. e = -1: rho + Q chi chi^dagger Q / (chi^dagger Q chi), Q = 1 - rho; refused where the free
        size is 0. e = +1: rho + chi chi^dagger / (chi^dagger chi). Returns the free size (scaled) or None if refused."""
        if e == -1:
            F, Rc = self.free_size(chi)
            if F == 0:
                return 0
            v = [gs(gk(self.lam, a), b) for a, b in zip(chi, Rc)]
            self.R = [[ga(gk(F, self.R[i][j]), gm(v[i], gc(v[j]))) for j in range(self.n)] for i in range(self.n)]
            self.lam *= F
        else:
            F = sum(gn(a) for a in chi)
            self.R = [[ga(gk(F, self.R[i][j]), gk(self.lam, gm(chi[i], gc(chi[j])))) for j in range(self.n)] for i in range(self.n)]
            self.lam *= F
        self.reduce()
        return F

    def step(self, Uint, normD):
        """rho -> U rho U^dagger with Uint = D U integral (sparse): R -> Uint R Uint^dagger, lam -> lam N(D)."""
        n = self.n
        X = []
        for row in Uint:
            acc = [ZERO] * n
            for k, a in row.items():
                Rk = self.R[k]
                acc = [(p[0] + a[0] * b[0] - a[1] * b[1], p[1] + a[0] * b[1] + a[1] * b[0]) for p, b in zip(acc, Rk)]
            X.append(acc)
        Y = []
        for i in range(n):
            Xi = X[i]
            rowY = []
            for j in range(n):
                re = im = 0
                for k, a in Uint[j].items():
                    b = Xi[k]
                    # Xi[k] * conj(a)
                    re += b[0] * a[0] + b[1] * a[1]
                    im += b[1] * a[0] - b[0] * a[1]
                rowY.append((re, im))
            Y.append(rowY)
        self.R = Y
        self.lam *= normD
        self.reduce()

    def hermitian(self):
        return all(self.R[i][j] == gc(self.R[j][i]) for i in range(self.n) for j in range(i, self.n))

    def idempotent(self):
        """rho^2 = rho  <=>  R R = lam R."""
        RR = mmul(self.R, self.R)
        return all(RR[i][j] == gk(self.lam, self.R[i][j]) for i in range(self.n) for j in range(self.n))

    def trace(self):
        t = mtr(self.R)
        return t

    def block(self, x, m):
        return [[self.R[x * m + a][x * m + b] for b in range(m)] for a in range(m)]

    def cap_2x2(self, x, m=2):
        """At Node-clock x (m = 2): 1 - rho_xx and rho_xx positive, by trace >= 0 and det >= 0 of each (scaled)."""
        B = self.block(x, m)
        lam = self.lam
        a, d, b = B[0][0][0], B[1][1][0], B[0][1]
        hole_tr, hole_det = 2 * lam - a - d, (lam - a) * (lam - d) - gn(b)
        occ_tr, occ_det = a + d, a * d - gn(b)
        return hole_tr >= 0 and hole_det >= 0 and occ_tr >= 0 and occ_det >= 0, (hole_tr, hole_det, occ_tr, occ_det)

    def power_traces(self, k):
        """Tr rho^j for j = 1..k as Fractions (the spectrum's invariants)."""
        out = []
        P = [row[:] for row in self.R]
        for j in range(1, k + 1):
            if j > 1:
                P = mmul(P, self.R)
            t = mtr(P)
            out.append((Fr(t[0], self.lam ** j), Fr(t[1], self.lam ** j)))
        return out

def shear(x, r, y, num, dn):
    """Carried shear x <- x - (num / dn) y: dn x' + r' = dn x + r - num y, 0 <= r' < dn."""
    tot = dn * x + r - num * y
    return tot // dn, tot % dn


def unshear(x, r, y, num, dn):
    tot = dn * x + r + num * y
    return tot // dn, tot % dn


def turn_carried(a, ra, b, rb, p, s, d, sign, going):
    """The plane turn by sign*theta (cos = p/d, sin = s/d) as three carried shears: t = s/(d + p), then sin, then t.
    x <- x - t y ; y <- y + S x ; x <- x - t y   (for +theta; the sign flips t and S)."""
    t_num, t_den = sign * s, d + p
    S_num, S_den = sign * s, d
    if going == 1:
        a, ra = shear(a, ra, b, t_num, t_den)
        b, rb = shear(b, rb, a, -S_num, S_den)
        a, ra = shear(a, ra, b, t_num, t_den)
    else:
        a, ra = unshear(a, ra, b, t_num, t_den)
        b, rb = unshear(b, rb, a, -S_num, S_den)
        a, ra = unshear(a, ra, b, t_num, t_den)
    return a, ra, b, rb


def carried_ring(p, s, d, L, ticks):
    """The ring's 1-D Dirac step with integer notches and carried remainders: shift (up +1, down -1), then the coin.
    The coin [[c, -is], [-is, c]] on (up, down) = (a + ib, c + id) turns the plane (a, d) by -theta and (b, c) by +theta."""
    rng = random.Random(7)
    A = 10 ** 6
    up = [(rng.randint(-A, A), rng.randint(-A, A)) for _ in range(L)]
    dn = [(rng.randint(-A, A), rng.randint(-A, A)) for _ in range(L)]
    fine = [[0, 0, 0, 0] for _ in range(L)]  # remainders of a, b, c, d
    start = (list(up), list(dn), [f[:] for f in fine])
    n0 = sum(gn(z) for z in up) + sum(gn(z) for z in dn)
    drifted, worst = 0, Fr(0)
    for _ in range(ticks):
        up = [up[(x - 1) % L] for x in range(L)]
        dn = [dn[(x + 1) % L] for x in range(L)]
        fine = [[fine[(x - 1) % L][0], fine[(x - 1) % L][1], fine[(x + 1) % L][2], fine[(x + 1) % L][3]] for x in range(L)]
        for x in range(L):
            a, b = up[x]
            c, e = dn[x]
            ra, rb, rc, re = fine[x]
            a, ra, e, re = turn_carried(a, ra, e, re, p, s, d, -1, 1)
            b, rb, c, rc = turn_carried(b, rb, c, rc, p, s, d, 1, 1)
            up[x], dn[x], fine[x] = (a, b), (c, e), [ra, rb, rc, re]
        nn = sum(gn(z) for z in up) + sum(gn(z) for z in dn)
        if nn != n0:
            drifted += 1
            worst = max(worst, Fr(abs(nn - n0), n0))
    for _ in range(ticks):
        for x in range(L):
            a, b = up[x]
            c, e = dn[x]
            ra, rb, rc, re = fine[x]
            a, ra, e, re = turn_carried(a, ra, e, re, p, s, d, -1, -1)
            b, rb, c, rc = turn_carried(b, rb, c, rc, p, s, d, 1, -1)
            up[x], dn[x], fine[x] = (a, b), (c, e), [ra, rb, rc, re]
        up = [up[(x + 1) % L] for x in range(L)]
        dn = [dn[(x - 1) % L] for x in range(L)]
        fine = [[fine[(x + 1) % L][0], fine[(x + 1) % L][1], fine[(x - 1) % L][2], fine[(x - 1) % L][3]] for x in range(L)]
    rev = (up, dn, fine) == start

def dec(x, digits=3):
    """A non-negative Fraction as a decimal string in scientific form, by integer arithmetic alone (no float)."""
    if x == 0:
        return "0"
    e = 0
    while x >= 10:
        x /= 10
        e += 1
    while x < 1:
        x *= 10
        e -= 1
    scaled = (x * 10 ** digits).numerator * 2 // (x * 10 ** digits).denominator
    scaled = (scaled + 1) // 2
    s = str(scaled)
    return f"{s[0]}.{s[1:]}e{e}"


def collision(p, s, d):
    """Two states (x, y, rx, ry) with the same carried image under the whole turn."""
    seen = {}
    for x in range(-2, 3):
        for y in range(-2, 3):
            for rx in range(d):
                for ry in range(d):
                    nx, ny = p * x - s * y + rx, s * x + p * y + ry
                    key = (nx, ny)
                    if key in seen:
                        return f"{seen[key]} and {(x, y, rx, ry)} both carry to {(nx // d, ny // d, nx % d, ny % d)}"
                    seen[key] = (x, y, rx, ry)
    return None

generic lay; the cap at every Node-clock and every tick.

  venv314/bin/python -I c3_tensor.py <repo>/src            the claims (must print 0 failures)
  venv314/bin/python -I c3_tensor.py <repo>/src mutants    the mutations (each must fail)

The tensor is held as rho = R / lam, R Gaussian integers, lam a positive integer: the step R -> (D U) R (D U)^dagger,
lam -> lam N(D); the lay with e = -1: R -> F R + v v^dagger, lam -> lam F, v = lam chi - R chi,
F = lam |chi|^2 - chi^dagger R chi (lam times the Pauli free size; refused where F = 0); with e = +1:
R -> |chi|^2 R + lam chi chi^dagger. Checked exactly at every tick: R Hermitian, R R = lam R (rho^2 = rho),
Tr R = N lam, and at every Node-clock lam - R_xx and R_xx positive (2x2: trace >= 0 and det >= 0; 4x4: every
elementary symmetric function of the eigenvalues >= 0).
Integers and Fractions only.

def scaled_step(U, D):
    S = sp_scale(fr(D), U)
    assert sp_integral(S)
    return sp_int(S), gn(D)


def block_psd(B, lam):
    """lam I - B and B positive semidefinite (B Hermitian, Gaussian integers), exact."""
    m = len(B)
    if m == 2:
        a, d, b = B[0][0][0], B[1][1][0], B[0][1]
        return (2 * lam - a - d >= 0 and (lam - a) * (lam - d) - gn(b) >= 0 and a + d >= 0 and a * d - gn(b) >= 0)
    for M in (B, [[gs((lam, 0) if i == j else ZERO, B[i][j]) for j in range(m)] for i in range(m)]):
        cp = charpoly(M)  # det(x - M) = x^m - e1 x^(m-1) + e2 x^(m-2) - ...
        for k in range(1, m + 1):
            ek = cp[k][0] * (-1) ** k
            if ek < 0:
                return False
    return True


def occupation_top_above_one(B, lam):
    """True where the larger eigenvalue of rho_xx = B / lam exceeds 1 (2x2)."""
    a, d, b = B[0][0][0], B[1][1][0], B[0][1]
    return not (2 * lam - a - d >= 0 and (lam - a) * (lam - d) - gn(b) >= 0)


def run_board(label, board, Uint, normD, plan, ticks, hands_check_every=0, e=-1):
    """Run a lay plan and the step; check everything at every tick. plan: {tick: [chi, ...]}."""
    T = Tensor(board.n)
    hands = []  # (phi scaled by the same D^t, norm scaled) for the Cauchy-Binet and projector identities
    N = 0
    stats = dict(ticks=0, herm=0, idem=0, trace=0, caps=0, cap_ok=0, laid=0, refused=0, local_free=0, lays=0,
                 hands_ok=0, hands_checked=0, cb_ok=0, cb_checked=0)
    for t in range(ticks + 1):
        for chi in plan.get(t, []):
            stats["lays"] += 1
            F, _Rc = T.free_size(chi)
            # the free size of a newcomer held at one Node-clock reads that Node-clock's block alone
            sites = {i // board.m for i, a in enumerate(chi) if a[0] or a[1]}
            if len(sites) == 1:
                x = sites.pop()
                s = chi[x * board.m:(x + 1) * board.m]
                B = T.block(x, board.m)
                q = ZERO
                for i in range(board.m):
                    for j in range(board.m):
                        q = ga(q, gm(gm(gc(s[i]), B[i][j]), s[j]))
                stats["local_free"] += F == T.lam * sum(gn(a) for a in s) - q[0]
            else:
                stats["local_free"] += 1
            if e == -1:
                if F == 0:
                    stats["refused"] += 1
                    stats.setdefault("outcomes", []).append("refused")
                    continue
                stats.setdefault("outcomes", []).append("laid")
                v = T.matvec(chi)
                v = [gs(gk(T.lam, a), b) for a, b in zip(chi, v)]
                hands.append([v, F * T.lam])  # phi = v / lam, |phi|^2 = F / lam  ->  phi phi^dagger / |phi|^2 = v v^dagger / (lam F)
                T.lay(chi, -1)
            else:
                hands.append([chi, sum(gn(a) for a in chi)])
                T.lay(chi, +1)
            N += 1
            stats["laid"] += 1
        stats["ticks"] += 1
        stats["herm"] += T.hermitian()
        if e == -1:
            stats["idem"] += T.idempotent()
        tr = T.trace()
        stats["trace"] += tr == (N * T.lam, 0)
        for x in range(board.V):
            stats["caps"] += 1
            stats["cap_ok"] += block_psd(T.block(x, board.m), T.lam)
        if hands_check_every and t % hands_check_every == 0 and hands and e == -1:
            stats["hands_checked"] += 1
            stats["hands_ok"] += projector_from_hands(T, hands)
            ok_cb, n_cb = cauchy_binet(T, hands, board)
            stats["cb_checked"] += n_cb
            stats["cb_ok"] += ok_cb
        if t < ticks:
            T.step(Uint, normD)
            for h in hands:
                h[0] = sp_apply(Uint, h[0])
                h[1] *= normD
    stats["N"] = N
    stats["bits"] = max(max(abs(v[0]).bit_length(), abs(v[1]).bit_length()) for row in T.R for v in row)
    return stats, T, hands


def projector_from_hands(T, hands):
    """rho = SUM_k phi_k phi_k^dagger / |phi_k|^2 with the hands' own norms (they stay orthogonal under the unitary step)."""
    n = T.n
    acc = [[(Fr(0), Fr(0))] * n for _ in range(n)]
    for v, nv in hands:
        for i in range(n):
            vi = v[i]
            if not (vi[0] or vi[1]):
                continue
            for j in range(n):
                p = gm(vi, gc(v[j]))
                if p[0] or p[1]:
                    a = acc[i][j]
                    acc[i][j] = (a[0] + Fr(p[0], nv), a[1] + Fr(p[1], nv))
    lam = T.lam
    return all(acc[i][j][0] * lam == T.R[i][j][0] and acc[i][j][1] * lam == T.R[i][j][1] for i in range(n) for j in range(n))


def cauchy_binet(T, hands, board):
    """det rho_xx = SUM_{k<l} N(det[phi_k(x), phi_l(x)]) / (|phi_k|^2 |phi_l|^2): the click's pair at one Node-clock is
    the sum of draft E's two-quantum joint sizes (2 components)."""
    if board.m != 2:
        return 0, 0
    ok = cnt = 0
    for x in range(board.V):
        B = T.block(x, 2)
        det = Fr(B[0][0][0] * B[1][1][0] - gn(B[0][1]), T.lam * T.lam)
        tot = Fr(0)
        for k in range(len(hands)):
            for l in range(k + 1, len(hands)):
                a, b = hands[k][0][2 * x:2 * x + 2], hands[l][0][2 * x:2 * x + 2]
                dd = gs(gm(a[0], b[1]), gm(a[1], b[0]))
                tot += Fr(gn(dd), hands[k][1] * hands[l][1])
        cnt += 1
        ok += det == tot
    return ok, cnt


def ring_plan(board, rng):
    """Six quanta on a ring: two at x0 (they fill it), a third there (must be refused), one at x0 + 1; after the spread,
    two more at x0 and one spread newcomer. The expected outcomes, in order: laid, laid, refused, laid, laid, laid, laid."""
    up, dn = [(1, 0), ZERO], [ZERO, (1, 0)]
    x0 = 0
    return {
        0: [local_vec(board, x0, up), local_vec(board, x0, [(1, 1), (2, -1)]), local_vec(board, x0, [(3, 0), (0, 1)]),
            local_vec(board, (x0 + 1) % board.V, dn)],
        25: [local_vec(board, x0, up), local_vec(board, x0, dn)],
        60: [rand_gauss_vec(rng, board.n, 2)],
    }


def torus_plan(board, rng):

    one = [(1, 0)] + [ZERO] * (m - 1)

        7: [local_vec(board, 0, one), rand_gauss_vec(rng, board.n, 2)],

    }
    return plan

def ginner(u, v):
    t = ZERO
    for a, b in zip(u, v):
        t = ga(t, gm(gc(a), b))
    return t


def gram(vs):
    return [[ginner(u, v) for v in vs] for u in vs]


def immanant(G, e):
    """SUM over permutations of e^inversions PROD G[i][pi(i)]: det for e = -1, perm for e = +1 (Fractions/ints)."""
    from itertools import permutations
    n = len(G)
    tot = ZERO
    for pi in permutations(range(n)):
        inv = sum(1 for i in range(n) for j in range(i + 1, n) if pi[i] > pi[j])
        term = (e ** inv, 0)
        for i in range(n):
            term = gm(term, G[i][pi[i]])
        tot = ga(tot, term)
    return tot


def one_body(vs, e):
    """The one-body density of the e-symmetrized state of the hands vs: rho(x,y) = SUM_ij v_i(x) conj(v_j(y)) e^(i+j)
    imm(G minus row j, column i) / imm(G) (the sign of the minor's position for e = -1)."""
    n, k = len(vs[0]), len(vs)
    G = gram(vs)
    Z = immanant(G, e)
    rho = [[(Fr(0), Fr(0))] * n for _ in range(n)]
    for i in range(k):
        for j in range(k):
            minor = [[G[r][c] for c in range(k) if c != i] for r in range(k) if r != j]
            w = immanant(minor, e) if minor else (1, 0)
            sign = (e ** (i + j), 0)
            w = gm(sign, w)
            for x in range(n):
                a = gm(vs[i][x], w)
                if not (a[0] or a[1]):
                    continue
                for y in range(n):
                    b = gm(a, gc(vs[j][y]))
                    rho[x][y] = (rho[x][y][0] + b[0], rho[x][y][1] + b[1])
    Zf = Z[0]
    assert Z[1] == 0
    return [[(v[0] / Zf, v[1] / Zf) for v in row] for row in rho]


def tensor_rho(T):
    return [[(Fr(v[0], T.lam), Fr(v[1], T.lam)) for v in row] for row in T.R]

def graph_dist(board, i, j):

def gdivf(a, b):

def column_basis(A):
    """Indices of a maximal set of independent columns of A (Gaussian elimination over Q(i))."""
    rows, cols = len(A), len(A[0])
    M = [[(Fr(v[0]), Fr(v[1])) for v in row] for row in A]
    piv_cols, r = [], 0
    for c in range(cols):
        p = next((i for i in range(r, rows) if M[i][c][0] or M[i][c][1]), None)
        if p is None:
            continue
        M[r], M[p] = M[p], M[r]
        for i in range(rows):
            if i != r and (M[i][c][0] or M[i][c][1]):
                f = gdivf(M[i][c], M[r][c])
                M[i] = [gs(x, gm(f, y)) for x, y in zip(M[i], M[r])]
        piv_cols.append(c)
        r += 1
        if r == rows:
            break
    return piv_cols


def inverse(A):
    n = len(A)
    M = [[(Fr(v[0]), Fr(v[1])) for v in row] + [((Fr(1), Fr(0)) if i == j else (Fr(0), Fr(0))) for j in range(n)] for i, row in enumerate(A)]
    for c in range(n):
        p = next(i for i in range(c, n) if M[i][c][0] or M[i][c][1])
        M[c], M[p] = M[p], M[c]
        inv = gdivf((Fr(1), Fr(0)), M[c][c])
        M[c] = [gm(inv, x) for x in M[c]]
        for i in range(n):
            if i != c and (M[i][c][0] or M[i][c][1]):
                f = M[i][c]
                M[i] = [gs(x, gm(f, y)) for x, y in zip(M[i], M[c])]
    return [row[n:] for row in M]


def range_projector(A):
    """The projector onto the column space of A: B (B^dagger B)^-1 B^dagger, B the independent columns."""
    n = len(A)
    cols = column_basis(A)
    if not cols:
        return [[(Fr(0), Fr(0))] * n for _ in range(n)], 0
    B = [[A[i][c] for c in cols] for i in range(n)]
    r = len(cols)
    G = [[sum_g(gm(gc(B[k][a]), B[k][b]) for k in range(n)) for b in range(r)] for a in range(r)]
    Gi = inverse(G)
    BG = [[sum_g(gm(B[i][a], Gi[a][b]) for a in range(r)) for b in range(r)] for i in range(n)]
    P = [[sum_g(gm(BG[i][b], gc(B[j][b])) for b in range(r)) for j in range(n)] for i in range(n)]
    return P, r


def sum_g(it):
    t = (Fr(0), Fr(0))

def is_projector(rho):
    n = len(rho)

            t = sum_g(gm(rho[i][k], rho[k][j]) for k in range(n))

    return True

"""David's check: each junction of the walk, times a Gaussian unit phase, is three shears with
Gaussian coefficients over 2 at most; carried with Rule3's rounding, each shear is undone exactly.
Exact: Fraction pairs only."""
from fractions import Fraction as Fr
import random

class G:
    __slots__ = ("re", "im")
    def __init__(s, re, im=0): s.re = Fr(re); s.im = Fr(im)
    def __add__(s, o): o = o if isinstance(o, G) else G(o); return G(s.re + o.re, s.im + o.im)
    __radd__ = __add__
    def __sub__(s, o): o = o if isinstance(o, G) else G(o); return G(s.re - o.re, s.im - o.im)
    def __rsub__(s, o): return G(o) - s
    def __mul__(s, o): o = o if isinstance(o, G) else G(o); return G(s.re*o.re - s.im*o.im, s.re*o.im + s.im*o.re)
    __rmul__ = __mul__
    def conj(s): return G(s.re, -s.im)
    def norm(s): return s.re*s.re + s.im*s.im
    def inv(s): n = s.norm(); return G(s.re/n, -s.im/n)
    def __truediv__(s, o): o = o if isinstance(o, G) else G(o); return s * o.inv()
    def __eq__(s, o): o = o if isinstance(o, G) else G(o); return s.re == o.re and s.im == o.im
    def __repr__(s): return f"({s.re}{'+' if s.im >= 0 else '-'}{abs(s.im)}i)"
    def den(s): return max(s.re.denominator, s.im.denominator)

def R(z):  # Rule3's rounding of a Gaussian rational to the nearest Gaussian integer, half up, per part
    def r1(x): return (x.numerator * 2 + x.denominator) // (2 * x.denominator)
    return G(r1(z.re), r1(z.im))

def carried(xy, coefs, back=False):
    x, y = xy
    u, p, c, q = coefs
    steps = [("up", q), ("low", c), ("up", p)]
    if not back:
        for kind, k in steps:
            if kind == "up": x = x + R(k * y)
            else: y = y + R(k * x)
        y = y * u
    else:
        y = y * u.inv()
        for kind, k in reversed(steps):
            if kind == "up": x = x - R(k * y)
            else: y = y - R(k * x)
    return (x, y)
