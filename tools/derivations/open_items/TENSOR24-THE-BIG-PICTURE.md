## 2. The one mechanism: the carry

**Clocks.** Every step of every gear ends in a carry, n + r = q d + r' with 0 <= r' < d. The quotient q leaves: the gear's notch, the drive's whole windings, the dial's beat, a click. The remainder r' stays in a fine tooth.
- **The quotient is the arrow.** Once written in the record, the reversed run does not undo it (the owner's decision (o)).
- **The remainder is the memory.** It keeps every bit, so the step runs back exactly (Postulate 4).
  - So the remainders do not prevent the way back; they make it exact.
  - What keeps a cycle from repeating the last is the quotients written.
- **The remainders are also the digits every draw reads** (section 5.2), so they are the source of the choices as well.

**Acts** (algebra/carry.py, the one place a division is written):
- carry(n, d, r) = ((n + r) div d, (n + r) mod d), with d a teeth count of at least 1;
- uncarry(q, d, r') = q d + r', the run back;
- nonneg(n) = (n div (n n + 1)) + 1, the one whether: 1 where n >= 0, and 0 below;
- choose(k, x, y) = k x + (1 - k) y, the choice by a bit.

**Tensors.** Each is elementwise over the board's arrays of Python integers (numpy object arrays). So no product wraps, and the same code serves a number and an array.

**Status:** the law's Rule3. The arrow and the exact way back are derived (Postulate 4, decision (o)).

### 5.1 The whole click

4. **The books:**

### 5.2 The split click

**Clocks.** A spread hand is decided by a tournament of two-part splits along the Meshes.
- At one Mesh, the two parts' sizes meet, and the draw at the Mesh's Node-clock picks a side by the sizes.
- The winner keeps the whole winding of both, and the loser's wind travels to it, one Mesh a tick.
- The click is final once the closure has crossed the hand.
- The draw reads the remainders, which no strike can read. So the choice is set on the board and fair to every reader.

**Acts** (DAVID-TENSOR24-THE-FAIR-DRAW-AND-POSITION.md, for stage 9):

- **The part:** the rank count, part = SUM_i nonneg(d - S_i), with S_i the cumulative sizes. There is no sort and no if.
- **The law's form** (the principle's item (5)): c from the Node-clock's own remainders and one Mesh's digit, then t by a second carry. d = (c + V) mod L is that carry, with the beat count added.
- **On twins against a detector:**

- **The tournament:** the larger-neighbour matching, a schedule the 24 leave alike. The winner keeps both windings, and the loser's wind moves one Mesh a tick.
- **The closure:** a token carried along the Meshes, one Mesh a tick; for a pair, along the birth's Mesh.
- **What it writes:** the draw writes nothing, since it is a reading of the state at its beat. The record carries the part, and the winner's windings and the losers' moves are books.
