There w = 6 rim Gamma^2 G^2 (the teeth), R = 2 pinion Gamma^2 G^2 (each of the six grips), D = 12 (rim - pinion) Gamma^2 G^2 (the spring), S = 2 w - D - SUM_j R_j (the hold). One quantum is the sweep key / 2 (the setting's count, DAVID-AMPLITUDES section 7). hbar_L = 3 key rim, the light's winding. g = pinion + i s, the train's pair as one Gaussian integer, N(g) = rim^2 (den's circle, MS-S2).

## 0. The answer in five lines

1. **One mass, one Gaussian integer.** A train's mass is its pair g = pinion + i s on den's circle. Its three readings are its three shadows: the sine Im g / rim (the wind one quantum holds at rest), the beat arg g (the hand's turn per tick), the inertia 3 Im g / Re g (the dispersion's curvature). PROVED.
2. **The one exact reading is the sine.** The winding w_c = 3 key s is the least wind a quantum of the train can hold in any state, reached only at rest (a theorem of the one formula). Per mode the wind per quantum is hbar_L sin w(k), the lattice's Planck relation with one hbar_L for every train. So the beat is the mass misread through E = hbar w, and the inertia is the mass misread through light's c^2 where the train's own c_T^2 = c^2 cos w0 holds: E0 = m2 c_T^2 exactly. PROVED and CHECKED.
3. **The second reading from the clicks** is the chimes. def one_site_wind(clock, k, where, notches, gearing):
    """The head's own act: the hand k's gears put to zero, the notches advanced at one Node-clock by the head's
    advance, the head's hands.wind summed over the window (as unspring.fitted_windings_of reads it)."""
    hand = clock.hands()[k]
    held = hand.gears
    hand.gears = [Gear(zeros(clock.size), zeros(clock.size), g.fine, g.teeth) for g in held]
    advance(clock, k, where, notches)
    window = sorted(set(window_clocks(clock, where)))
    found = sum(int(v) for v in hands.wind(clock, hand.gears, gearing, window))
    hand.gears = held
    return found

# Gaussian numbers as pairs (re, im) of int/Fraction
def gm(a, b):
    return (a[0] * b[0] - a[1] * b[1], a[0] * b[1] + a[1] * b[0])


def ga(a, b):
    return (a[0] + b[0], a[1] + b[1])


def gs(a, b):
    return (a[0] - b[0], a[1] - b[1])


def gk(k, a):
    return (k * a[0], k * a[1])


def gc(a):
    return (a[0], -a[1])


def n2(a):
    return a[0] * a[0] + a[1] * a[1]


IPOW = [(1, 0), (0, 1), (-1, 0), (0, -1)]
COS4 = [1, 0, -1, 0]

L = 4
SITES = [(x, y, z) for x in range(L) for y in range(L) for z in range(L)]
NB = []
for (x, y, z) in SITES:
    NB.append([((x + 1) % L, y, z), ((x - 1) % L, y, z), (x, (y + 1) % L, z),
               (x, (y - 1) % L, z), (x, y, (z + 1) % L), (x, y, (z - 1) % L)])
IDX = {s: i for i, s in enumerate(SITES)}
NBI = [[IDX[t] for t in nb] for nb in NB]


def wind_norm(a, am, p, rim, S=0):
    """E' = E / (2 Gamma^2 G^2): 3 rim SUM(|a|^2+|a-|^2) - p Re SUM_x SUM_j conj(a_x) a-_(x+j)
    (the engine's hands.wind at the vacuum, globally; S = 0 at the vacuum)."""
    e = 0
    cross = 0
    for i in range(len(a)):
        e += n2(a[i]) + n2(am[i])
        for j in NBI[i]:
            c = gm(gc(a[i]), am[j])
            cross += c[0]
    return 3 * rim * e - p * cross


def sweep(a, am):
    return sum(gm(gc(a[i]), am[i])[1] for i in range(len(a)))


def dft(a):
    """alpha_n = SUM_x conj(i^(n.x)) a_x, exact Gaussian integers; n in SITES order."""
    out = []
    for n in SITES:
        acc = (0, 0)
        for xi, x in enumerate(SITES):
            ph = IPOW[(-(n[0] * x[0] + n[1] * x[1] + n[2] * x[2])) % 4]
            acc = ga(acc, gm(ph, a[xi]))
        out.append(acc)
    return out


def pyth(limit):
    """Primitive Pythagorean triples (a, b, h) with h <= limit."""
    out = []
    m = 2
    while m * m + 1 <= limit:
        for n in range(1, m):
            if (m - n) % 2 == 1:
                from math import gcd
                if gcd(m, n) == 1:
                    h = m * m + n * n
                    if h <= limit:
                        out.append((m * m - n * n, 2 * m * n, h))
        m += 1
    return out
