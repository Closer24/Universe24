## 5. D4 in the whitelist form (math MINOR 2; the 11:06 ruling, Q3)

**Replaces** DECODE3i lines 307-313.
- **The rule.** D4 is a static check of each conversion's code over every parameter kind (positional, keyword-only,
  *args, **kwargs). A conversion may hold only:
  - calls of own(), whose first argument is a lines parameter (a name ending in _lines) and whose second, positional or
    r=, is a round parameter;
  - arithmetic over those calls, and constants;
  - its return.
  Every other name, call, node or parameter kind is refused.
- **MEASURED** (decode3j D):
  - allowed: C-a on own counts, and the honest keyword C-a, `own(A_lines, r=take) - ...`;
  - refused:
    - the mutant on rounds, the negated mutant (the name outside own());
    - the summed mutant (a call of sum);
    - `own(range(BIG), take)` (own()'s first argument is no lines parameter);
    - the fields read through locals() (a call of locals);
    - `*f` (a *args parameter);
    - keyword-only fields used bare (the name outside own()).
