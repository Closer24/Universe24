# Retired standalone generic vector lab

The independent vector-lab runtime, input definitions, demos and 52 contract
cases were removed from the active checkout during test and experiment cleanup.
They were a separate mechanism prototype, never the active Simulation engine.

The [complete historical laboratory](https://github.com/Closer24/Universe24/tree/4796cb256cbdbd830aa29cc3038fea98087de58b/tools/generic_vector_lab)
retains its code, instructions and recorded limitations for reproduction.

Use the active [Node processor](../../docs/NODE_VECTOR_PROCESSOR.md),
[local conversions](../../docs/LOCAL_CONVERSIONS.md) and
[configuration guide](../../skills/simulation-configuration/SKILL.md) for current work.
These owners retain their own contract tests; they do not certify the retired lab.
