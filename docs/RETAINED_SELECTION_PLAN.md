# Retained selection: eight-lane construction and acceptance plan

The previous phase observer recorded interference but could not change its
carrier. This investigation adds an actual reversible local preference,
retained record feedback, and a reciprocal homogeneous apparatus source.
They run through the unchanged integer Engine. They are distinct constructions
with explicit interfaces, not a completed derivation of growing complexity or
quantum measurement.

The work is coordinated in [issue #45](https://github.com/Closer24/Universe24/issues/45),
with allocation and physical-source handoffs in [#40](https://github.com/Closer24/Universe24/issues/40)
and [#41](https://github.com/Closer24/Universe24/issues/41). Eight researchers
worked in two waves of six and two, followed by independent review and joint
reproduction. The actual execution base is PR49 commit
`a3013a9d91ae5ff74ed8b4f511e03ac221425b98`, descended from main
`4c494c1188f70eb8a677bf59765cc6e8571c6b88`. The corrected frame source is
independently pinned to PR50 commit
`62202fdccdd9a40d5dbbec104de6f97d9587a999`.

## Step 1: synchronize through the exact update

Every construction retains the same rule:

```text
ell, r_next = divmod(2*u + r, 6)
a_next = b
b_next = ell - a
```

For one channel, `u=3b` gives `(a,b)->(b,b-a)`, exact period six and invariant
`a²+b²-ab`. A symmetric face-matching operator gives a corresponding coupled
positive quadratic invariant. These are bounded computational clock controls.
Neither a shared Engine update nor phase synchronization establishes physical
proper time or metric-calibrated signals.

More generally, let `F` be a reversible three-bit collision followed by streaming
only one lane by one face. Its inverse reads that lane from the opposite face.
Both admit cubic strict-face-local polynomials. Set

```text
u = 3 * (F(b) + F^-1(b))
initial a = F^-1(b), initial b Boolean, every r in 0..5 retained
```

Then `ell=F(b)+F^-1(b)`, `r_next=r`, and `b_next=F(b)`. The preparation relation
is invariant. No clipping, reset or hidden state bank is used. The underlying
integer update also rewinds outside this sector, but its Boolean interpretation
does not extend there. Arbitrary old history cannot be silently substituted.

## Step 2: implement preference inside the board

At each site use retained bits `(m,x,y)` and define
`s=y(1-x)`, `m'=m XOR s`, then swap `x,y` exactly when `m'=1`.
For ready memory `m=0`, the carrier output is `(x OR y,x AND y)` and `m'`
retains the input order. The full gate is a permutation, with nontrivial cycle
`001 -> 110 -> 101 -> 001`. Carrier occupancy `x+y` is conserved; total
three-bit Hamming weight is not a physical energy invariant.

The compiled law uses three channels and 22 monomials. Its streaming lane
carries the actual output. In 24 matched interventions, the complete initial
carrier `(a,b,r)` agrees while memory differs; the later carrier changes.
Removing memory-controlled routing removes the response. Ready memory is a
consumed preparation resource: it is not reset, and later collisions can undo
the sorting. Preference for one output port is not preference for complexity.

The arithmetic click remains a passive report of the transition. It cannot
reach back and choose the next state. The causal object behind a possible
"selecting click" is the retained local state and its fixed interaction.

## Step 3: acquire a record and use it later

A separate native pulse control writes memory velocity `v=b_m-a_m` with
`u_m=6b_m+3c²`, so `v_next=v+c²`. The pulse arrives at update1, the record
appears at2, and the downstream response appears at3. It persists through8;
the periodic pulse returns and writes again at9. Complete rewind retains both
the pulse and the record history. No-source produces no record; detached
feedback preserves the record but removes the later response.
Two prepared pulses write two records, explicitly failing unconditional
exclusive measurement.

This pointer control is not the Boolean sorter. It demonstrates a storage and
feedback interface that must separately be assigned physical source/stress.

## Step 4: couple apparatus and carrier within the budget

The corrected full-frame45 is explicitly massive, `m²=1`. Append neutral
apparatus position and momentum `q,p`, for 47 retained channels. Use

```text
I = phi² + chi²
W = omega²*q²/2 + g*q*I
q_dot = p
p_dot = tr(K)*p - omega²*q - g*I
delta(Pi_phi_dot) = -2*g*q*phi
delta(Pi_chi_dot) = -2*g*q*chi
rho_app = p²/2 + W
stress_app = (p²/2-W) * identity
```

The diagonal extrinsic-curvature source gains `-W`, and the Hamiltonian
constraint gains `-2*rho_app`. Reciprocal carrier/apparatus exchange cancels
in the homogeneous continuum energy identity; the neutral interaction leaves
the U(1) torque zero. With `dt=1/32`, `omega²=1`, `g=1/4`, the compiled
projective law has 47 channels and 909 cubic face-local terms.

Opposite apparatus momenta initially have identical source stress and identical
original45 fields. The homogeneous initial H/M/Gauss constraints are exactly
zero. Carrier momentum changes by update2 and carrier position by3; matched
`g=0` controls eliminate the source difference. These are equal-stress
interventions, not identical complete apparatus states. The old projective
denominator is zero boundary memory; only current positive-denominator ratios
are interpreted physically.

The interaction is globally unbounded below after eliminating `q`. Finite-step
Hamiltonian drift remains, and massless controls leave the declared positive
effective-mass domain. Without spatial apparatus gradients/momentum dynamics,
this is a homogeneous normal-frame source, not a generally covariant moving
detector. Texture tests are algebraic response probes.

Appending one retained raw record uses the last slot. Source-preserving48
exactly preserves sourced47. Active48 feeds the record into apparatus momentum:
a new record appears at2, changes apparatus momentum at3 and reaches carrier
by5. A matched old-memory intervention changes apparatus at1 and carrier
momentum at3. Both use the same immutable active tensor.

## Step 5: test growth and probability without hiding failures

The native growth protocol fixes 36 seeds/size/direction configurations, 24
updates, a recurring structural-motif score and arithmetic-event episodes.
There are 36 matching detached controls. Results are **0 passed, 30 failed,
6 blocked by too few episodes**. Frozen random patterns can score highly,
exposing a limitation of the proxy. No cosmological burst identification is
made. A finite Boolean board must recur and cannot have a state score that
strictly increases indefinitely at recurring episodes. That argument does
not exclude finite-window or unbounded-integer growth in another sector.

The native collision produces exactly one occupied output if and only if
`x+y=1`; its preferred-port outcome is `1-m`. A ready-memory preparation gives
probability1, whereas the uniform whole-sector one-particle conditional gives
1/2. More strongly, two stationary translation-invariant ensembles with the
same global one-particle count give preferred-lane probabilities1/3 and1.
Stationarity, orbit counting and a shared clock therefore do not select a
unique physical preparation measure. All 4,080 saved measure-control
transitions retain nondetections and double outcomes, scalar replay, complete
inverse, canonical records and contiguous trial chains.

The QCA comparator lifts the actual collision to a Hilbert permutation. It
can entangle a separately supplied coherent product input; a diagonal mixture
with the same weights does not have that coherence. The relational-clock
comparator supplies calibrated basis records and fresh-probe repeatability,
but retains global coherence and later uncomputes its record. These exact
reference calculations do not derive quantum preparation, one selected
outcome, Born's rule or a physical Bell instrument from an Engine trajectory.

## Step 6: reproduce, reject mismatches, then advance the open gates

```bash
# REFERENCE is a clean checkout of the exact PR50 commit stated above.
python -m unittest discover -s universe24/tests -t . -v
python -m validation.system_smoke --out runs/selection-system-smoke
python -m validation.selection.run_audits --reference "$REFERENCE" --out runs/retained-selection
python -m validation.selection.run_audits --collect --out runs/retained-selection
```

Use a fresh output directory. The joint runner verifies the reference Git
commit and materialized Python blob bytes, imports its equations in an isolated
subprocess, then compares every retained state through the current runtime.
It links the native truth table across clocks, sorter, Born and Hilbert audits;
links exact sourced47 bundles to both appended48 preparations; binds pointer
and phase reports to identical run/seed/law identities; checks source hashes;
and requires independent replay of all 19 saved runtime experiments. Complete
raw Born trials are additional evidence, not included in that count. CI runs
this same pipeline on Python3.11 and3.12. The compact checked-in evidence index
is [retained_selection.json](evidence/retained_selection.json); complete traces
are generated under `runs/` and retained as workflow artifacts.

The next construction must solve these concrete linked gaps: an in-budget
physical encoding of local preference; a bounded interaction with spatial
momentum and record stress; a replenishment mechanism for ready memory that
preserves information; an operational, gauge-invariant clock/click readout;
a declared preparation measure; and held-out growth on an explicitly stated
finite-window or unbounded-state domain. The present code supplies mechanisms
and counterexamples for those steps, not an accepted physical model.
