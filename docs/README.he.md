# Universe24 — מנוע גנרי

המערכת בנויה מקובייה מחזורית סגורה שצלעה L (לפחות 3). לכל אתר צומת אחת, לוח אחד, ו־48 ערוצים המוגדרים לפי החבורה 2O. בכל ערוץ נשמרים a,b,r.

לכל ערוץ שישה קלטים מששת השכנים המרחביים; אין קישורים פנימיים. צימוד אחד נגזר מחבורת 2O ומתאר חיבורים חתומים עם ערכים ‎-1,0,+1. בוחרים לפני הריצה שלושה סימני צירי גוף, ולא משנים אותם במהלכה.

החוק היחיד:
`(ell,r_next)=divmod(2*u+r,6); a_next=b; b_next=ell-a`.

תנאי ההתחלה נקבעים מקובץ JSON. יתר המרחב נמצא ברקע קבוע (0,0,2). הריצה קוראת את מצב כל הצמתים לפני חישוב מצבם הבא.

תצפיות וסיווג שלוש מחלקות אירועים C0,C1,C2 מתבצעים מחוץ למערכת בלבד, ואינם גורמים לעדכון, אישור, ביטול, או בחירת היסטוריה.

להרצה:
```bash
python -m unittest discover -s tests -v
python -m universe24 --config examples/impulse.json --audit
```

ההפיכות והבדיקות האלגבריות אינן הוכחה לפיזיקה, שימור אנרגיה פיזיקלית או קליקים בוחרים. המודל נשאר בסיס מחקרי בלבד.
