# Historical travelling-metric probe construction

The previous phase-metric and diagonal link-probe preset depended on the
removed variable-divisor construction. Its active runner is retired.

The [original algebra and run evidence](archive/pre-fixed-six/docs/PHASE_METRIC_EXPERIMENT.md)
record what that particular preset established and where it failed. Those
clock ratios, characteristic speeds and parameter choices are not fixed-six
results. A new valid tensor must be supplied before transferring any physical
interpretation.

The [fixed-six curl and retiming examples](LINEAR_SPIN2.md) retain exact
prepared travelling sectors. The [local pp-wave example](PPWAVE_PALATINI_LOCAL.md)
retains a different restricted metric construction. Its
[geodesic extension](PPWAVE_OPERATIONAL_ROUTE.md) has exact selected worldline
readouts but does not yet propagate those worldlines as packets on the board.

These are separate constructions with distinct assumptions. Passing a trace,
divergence or curvature check does not establish a common operational metric
for all clocks and matter.
