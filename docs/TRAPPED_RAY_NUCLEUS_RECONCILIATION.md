## Minimal interface closure

Physics/mathematics first identifies the existing common numerical operation
and admitted property sector. If a map is absent, document that specific gap and
any separately identified candidate; do not silently substitute a spring, fixed
gap, species force or hold flag.

1. **Complete ray participants:** immutable references to bounded resident or
   causally arrived ray/property bundles, preserving heading, phase, stock and
   continuation metadata. Evaluation projections create no duplicate owner.
2. **One shared operation:** the same coupling acts on admitted participants;
   family metadata supplies sector, scales and conserved readouts. No dispatch
   on particle labels, world coordinates or a desired bound-state outcome.
3. **Atomic outcomes:** identify retained complete participants, six outputs,
   recoil/products, remainders and output readiness. Retention/release is a law
   result, not a diagnostic binding label.
4. **Time and phase:** define retained and in-flight phase updates, respecting
   each interval and fixed `H`. Host time and playback frames supply no physical
   frequency.
5. **Exclusion and conserved readouts:** define any actual interaction boundary
   affecting free-ray self-exclusion. Count all ray, field, recoil and remainder
   owners. Derive claimed aggregate mass/inertia from those readouts rather
than seeding the desired answer.

An independent axial readout fixture may assign each ray amount `a` energy `a`
and momentum `+/-a` along one axis. The pair then has energy `2a`, momentum zero
and invariant mass squared `4a^2`; this tests readout ownership, not confinement.
For a nonaxial heading, `E=amount` with `P=amount*heading` is not a massless
physical convention when the heading length exceeds one. Exact energy/heading
units and transport timing must be declared before using such a benchmark.

Independent acceptance derives localization or finite residence from the same
matrix/property rule used for unbound scattering, with outgoing channels still
present. Preparing a state in a permanently retained block imposes confinement
and is insufficient. Require coupling-zero escape, actual perturbed-mode leakage
or funded release, label permutation, full energy/momentum ownership and a
movable/boost control. Trace persistent internal dynamics where claimed, and
distinguish phase recurrence from spatial motion. Only then test the surrounding
electron's localization and frequency under the same coupling.

Physics identifies the shared operator and readouts; mathematics closes exact
representation/invariants; architecture closes bounded participant/proposal
interfaces; developers implement published contracts; independent acceptance
fixes expectations before execution. Canonical HTML and the actual-state GIF
remain required. This reconciliation keeps the requested goal active while
preventing comparison fixtures from being certified as the target model.
