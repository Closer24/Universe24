   `pytest` collects only the living suites (three of the cancelled files error at collection
   today and stopped the whole run before this).

   cancelled test is collected; the selector selects none; the doc's tables parse under every
   section; no living module under `src/` imports a module of section 4, except the lines
   named in section 9.
