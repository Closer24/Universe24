## 2. THE RULE, atom-level-v1: the release at a closure of the difference of two closures

**(a) As section 6 names it, and the correction the derivation
demands.** ALGEBRA.md section 6 names the primitive

    w c = h_q x floor((sum over a of (A_a - A_ret_a)) / (N h)),   then A_ret_a := A_a.

Over one return of the closed loop j the sum is exactly `j N h` (section
1 (a)), so the whole part is j and the primitive as written releases
`h_q j` at EVERY return of a closed loop: the body's own circles, the
loop's whole action every turn, which decays the rung and is not a
release of a difference of two closures (the fact of records 874 and
881; the stability rule of DESIGN.md took the remainder instead). The
difference of two closures is `(j - i) N h`, the action of the loop
before against the loop after, and the record as section 6 has it holds
only the action of the loop after (`A_a - A_ret_a`): the correction the
derivation demands is one more held integer, the whole circles of the
LAST loop, `j_ret`, and the release

    g = j_ret - j   when positive,   0 otherwise;   w c = h_q g;   then A_ret_a := A_a, j_ret := j        (the corrected action form; j = floor(Delta A / (N h)) the whole circles of the loop just closed),

zero at every return of a body that stays on its loop (the stability),
`j - i` at the first return after the body has passed from the loop j to
the loop i, nothing on an ascent (a rise of the circles is a row absorbed,
the click's `p' = p + w c u_d`, not a release). This corrected form is
exact in the law's integers, generic, vector and local (the same five
integers as DESIGN.md's give rows plus one); section 3 (b) shows what it
gives, and why it is not the rule this file names.
