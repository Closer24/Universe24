The Boss launches every row of this table in parallel at the model owner's
GO, one session per group, and nothing that is not on it. The order is
PLAN.md 3.3 steps 1 to 4. "To write" names the writer; a world written
from a declaration is regenerated by its generator, its pin written into
`expectations.json` by the pins script BEFORE the run and never moved.
The run command of every world is the engine's one line from the
repository root:

    python -m event_universe --init <world.json> --output artifacts/<group>/<world>

and the reader of record of every massive world is

    PYTHONPATH=src python examples/events/massive_record/read_runs.py

(the clicks at W on the block's own record, the mean interval over the
hold, DETECTOR; the spectral peak GAMEBOARD beside), extended by the
builder with one function per new reader named below. The layer
declaration of every row is DECLARATIONS.md section 7 (every row stands
on its declared board); the ramp rule is section 8.
