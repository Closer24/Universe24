## 4. The cost (HOST) and the run commands

The cost, HOST, on the register's timings for the same worlds: the
coasting world 43 s; the four cart worlds about 5 s each; the six J4
worlds 0.3 s each; with `--jobs 4` about one minute of wall clock, one
process per world, the engine untouched; the readings seconds. STEP 2
end to end (the runs, the reader, the readings by kind in this file, one
commit, one push, the report) about one hour of a session.

```bash
# The worlds and the pins, before any run (already written; idempotent).
PYTHONPATH=src .venv/bin/python docs/designs/fail_rows/run_4ab_worlds.py

# STEP 2, on GO: the eleven runs, headless, one process per world.
PYTHONPATH=src .venv/bin/python tools/run_series.py --jobs 4 \
    --out artifacts/fail_rows_4ab docs/designs/fail_rows/worlds/*.json

# STEP 2: the readings by kind. (a) 4b's z by the register's own reader
# (the coasting world keeps series S's model id, so the tool finds it;
# the J4 worlds carry new model ids and the tool leaves them alone).
PYTHONPATH=src .venv/bin/python tools/covariant_readings.py artifacts/fail_rows_4ab
# (b) The stamp check of 4b, the k-ladder's four ratios and 4a's clicks,
# by the reader written at STEP 2 beside this file, `run_4ab_readings.py`:

PYTHONPATH=src .venv/bin/python docs/designs/fail_rows/run_4ab_readings.py artifacts/fail_rows_4ab
```
