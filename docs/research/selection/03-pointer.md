# A retained pulse record that changes the later board

The constructive result is a finite local memory mechanism. A causal pulse
changes a retained integer velocity; that velocity persists after the pulse
has left and changes a later retained response. The mechanism uses the fixed
Rule3 Engine, complete initial state and one immutable tensor. A passive click
reader neither chooses the outcome nor controls the future board.

This is a mechanical validation primitive. It does not establish a physical
quantum instrument, a Boolean winner, an energy-complete apparatus or Born
probabilities. The two-source control produces two records and is retained as
an exclusivity failure.

## Exact recurrence and invariant preparation

Use three native control channels: traveling pulse `c`, memory `m`, and board
response `f`. For a declared face direction `e`, construct

```text
u_c(x) = 3 [b_c(x+e) + b_c(x-e)]
u_m(x) = 6 b_m(x) + 3 b_c(x)^2
u_f(x) = 6 b_f(x) + 3 k [b_m(x)-a_m(x)]
```

All coefficients are exact integers. Each monomial uses the target and at most
one face neighbor; degree is at most two. The only old-`a` dependency is memory
to response, so the inverse dependency graph is acyclic. Since every input is
a multiple of three, every carry remains unchanged for all six allowed values.

Prepare `a_c(x)=b_c(x+e)`. The wave recurrence then gives
`b'_c(x)=b_c(x-e)`, and the same relation holds at the next step. Thus a compact
prepared pulse travels exactly one face per update without a scheduled runtime
injection. Its passage is a local clock event for this control; computational
updates are not claimed to be physical proper time.

Define the retained memory velocity `v=b_m-a_m`. The unchanged Rule3 law gives

```text
b'_m = 2 b_m - a_m + b_c^2
v'   = v + b_c^2
```

After the pulse leaves a node, `b_c=0` and `v'=v`. The memory position continues
to change; the persistent record is its velocity, not a stationary triple.
For the response, `b'_f-2b_f+a_f=k v`. Turning `k` to zero is a separate
predeclared disconnected tensor control; no switch is changed during a run.

## Predeclared finite protocol

The two detector nodes sit one face ahead of two distinct transverse source
lanes. All ports and all ticks are retained. A declared record label is present
exactly when its memory velocity is positive; no winner is selected if both
labels are present.

| Local update | Fresh single-source preparation |
| --- | --- |
| 0 | Both records ready, `v=0`; pulse not at detector |
| 1 | Pulse at first detector; record still zero |
| 2 | First velocity record becomes 1; response still zero |
| 3 | First later board response becomes 1 |
| 2 through 8, side length 7 | Velocity record remains 1 |
| 9 | Periodic pulse returns and writes again, giving velocity 2 |

No indefinite saturation or absorbing state is claimed. A finite reversible
system cannot acquire an attracting permanently reset bit while forgetting the
other retained alternatives. Unbounded integer memory avoids erasure here by
continuing to retain the full state; it does not provide an exclusive choice.

- **No source:** ready memory and response remain zero at both declared ports.
- **Disconnected response:** the same record forms, but later response stays

## Primary-source assumptions and transfer limits

1. [Zurek, *Decoherence, einselection, and the quantum origins of the
   classical*, §§II.1 and VI.2](https://arxiv.org/html/quant-ph/0105127v3)
   describes controlled correlations and memory observables within quantum
   theory. The relevant design lesson is to distinguish correlation creation,
   record retention and later readout. Its Hilbert-space, entanglement and
   environment assumptions are not supplied by a reversible integer map.
   Repeating a controlled flip can uncompute a record; persistence requires a
   declared interaction interval or protection mechanism.
2. [Schumacher and Werner, *Reversible Quantum Cellular
   Automata*](https://arxiv.org/pdf/quant-ph/0405174) defines causal automorphisms
   of finite-dimensional quantum-cell observable algebras. Its blockwise
   unitary structure establishes a quantum locality/reversibility framework,
   not a Born derivation for this classical integer tensor. We transfer only
   the requirement to bound support and retain a reversible global evolution.
3. [Brambilla, Tosini and Perinotti, *Local Measurement Theory for Quantum
   Cellular Automata*, arXiv:2610.26587](https://arxiv.org/abs/2610.26587),
   abstract inspected, uses local completely positive instruments composed
   over a causal cone. It motivates explicit timed protocols and complete
   outcomes. Those quantum instrument maps are assumptions of that framework;
   they cannot be imported as a proof that native integer records are quantum
   measurements. Full-text access was unavailable in this review.

These sources guide operational tests, not success labels. The next joint gate
is an accounted retained record that influences the actual sourced carrier,
with finite persistence, repeatability and all-trial exclusivity tested under
the same metric and allocation. Born and Bell remain separate open gates.
