Baseline: current GitHub main `7d238e84a2167a4d3fe7bc7942da0cbf97bd29b2`,
including the merged Frame48 and Bell/Born work. The active code and text
files were verified against GitHub blobs before this investigation. The
local reconstruction has different commit ancestry; it is not a new physical
model. No production evolution, seed API, detector classifier or parameter
was changed by this investigation.

## Result

The current board passes its declared causal and reversible controls. It
does **not** reproduce a loophole-free Bell violation. The separate quantum
reference reproduces a particular singlet prediction because it assumes the
joint Born distribution. A universe-wide common past or clock does not by
itself close this gap. Nor does fresh local randomness at the click.

## Why clocks and complexity weighting do not yet produce Bell

Let lambda contain the shared past, local retained clocks and messages,
source memory and any common random variable needed by a model. Under
setting independence and Bell-local factorization,

```text
P(A,B | x,y,lambda) = P(A | x,lambda) P(B | y,lambda)
rho(lambda | x,y) = rho(lambda).
```

The local means a_x,b_y lie in [-1,1], including when the outcomes are
sampled for the first time at measurement. For each lambda,

```text
|a0*(b0+b1) + a1*(b0-b1)|
  <= |b0+b1| + |b0-b1| = 2*max(|b0|,|b1|) <= 2.
```

Averaging with the same source weights in all contexts preserves the bound.
This continuous argument is the theorem; the finite-grid test is a check,
not its proof. Any local complexity-to-probability function satisfies the
same inequality under these assumptions. Giving more weight to complex
shared source histories also leaves the bound intact if those weights are
independent of the analyzer settings. Memory can be included in the past
conditioning; it requires an appropriate finite-statistics test, not an
assumption of identical independent trials.

Calling the entire universe one clock does not specify which of these
assumptions changes. A complete deterministic board with local updates and
independently varied analyzer preparations remains within this test's local
model. A theory could instead change factorization, setting independence,
or its causal assumptions; Bell's theorem does not exclude every conceivable
global-universe theory. Such a change needs an explicit mathematical law,
an operational preparation protocol and new testable predictions. It cannot
be supplied by selecting favorable C2 records after observing them.

The current external sampler has access to both settings and uses joint
singlet amplitudes. It therefore is not a Bell-local response model even
though its exact marginals are nonsignalling. This does not demonstrate a
usable faster-than-light signal, and Bell violations do not alone establish
such signals. It does identify where the nonfactorizable prediction currently
enters the software: the separately assumed reference, not the local Engine.

## What experimental agreement requires

Representative primary experiments establish substantially more than a
chosen score. Hensen et al. used event-ready electron-spin trials, efficient
readout and rapid random basis choices separated by 1.3 km; 245 trials gave
S=2.42 +/- 0.20 and p<=0.039 with device memory allowed [1]. Shalm et al.
used entangled photons, spacelike separation, high-efficiency detection and
an analysis that includes nondetections. Their most significant adjusted
p-value was 2.3e-7 after accounting for setting predictability [2]. These
are examples of established benchmarks, not a claim to survey all recent
experiments or to extract raw data in this investigation.

Shalm's published protocol defines local trials and a stopping rule in
advance and uses a memory-robust hypothesis test. A prediction-based-ratio
method can also accommodate changing states and local models with history
[3]. Selection and coincidence mechanisms need their own treatment [4].
Our current exact enumeration has no sampling uncertainty for its declared
finite controls, but supplies neither an experimental p-value nor a fit to
laboratory apparatus and noise.

The decisive gates are:

1. **Declare the joint-state and analyzer law.** Construct an entangled
   source and physically meaningful local analyzer choices from retained
   board data. Explain explicitly which Bell-local premise fails if the
   model predicts S>2. An unobserved universal clock is not an explanation
   without this law. Preserve observable no-signalling for arbitrary allowed
   local interventions, not just one symmetric setting table.
2. **Derive and calibrate the detector probabilities.** Use all specified
   trials and record no/double clicks. Predict full P(A,B|x,y), local
   marginals, single-detector rates and interference across a preregistered
   range of states and analyzer directions. Verify Born probabilities and
   conditional measurement updates on held-out cases; one fitted S is not
   sufficient. The spin singlet target E=-a dot b must not be confused with
   the double-angle polarization convention.
3. **Make the causal experiment operational.** Retain analyzer-setting
   generation and choices, event-ready heralding or fixed local trial IDs,
   measurement deadlines and all outcomes. Check setting/source independence
   under the model's declared causal assumptions. Avoid outcome-dependent
   selection or fitted coincidence windows. Relate board cones and recorded
   clocks to the physical metric rather than merely lattice adjacency.
4. **Evaluate predictions without fitting the test sample.** Freeze the
   tensor, source law, analyzer map, noise/detection model and stopping rule
   before testing. Compare full distributions against real data or known
   quantum targets over multiple states, angles, distances, efficiencies
   and time orders. Use a valid finite-sample Bell test with stated memory
   and setting-predictability assumptions. Passing these gates would be
   bounded experimental agreement, not proof of all of nature.
