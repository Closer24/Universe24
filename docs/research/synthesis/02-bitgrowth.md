# Projective bit growth: a restricted obstruction and an admissible preparation control

Owner: integration research task 2. Baseline: PR47
`621fc1f55800e50e1db5f6a30ce24bb83716a49a`.
This report changes no Engine, tensor constructor, decoder or physical gate.

The current projective construction necessarily has exponentially growing
retained bit length. Dividing out common factors cannot solve that cost in
the protected 44-channel family, and raw scale is not a dynamical gauge once
old-state memory contributes. These are statements about this construction,
not impossibility results for Universe24 or Einstein dynamics.

## Primary research connection

Bellon and Viallet, [Algebraic entropy](https://arxiv.org/abs/chao-dyn/9805006),
*Communications in Mathematical Physics* 204, 425–437 (1999),
[full paper](https://arxiv.org/pdf/chao-dyn/9805006), §§1–2, define algebraic
entropy through degrees of iterated rational maps after common polynomial
factors have been removed. Homogeneous representatives of the same rational
map permit such cancellation. This motivates checking removable factors,
but does not authorize deleting retained arithmetic state in a different
reversible lift. Their degree-growth concept is not a physical entropy or
an observed structural-complexity statistic. The integer bounds and
counterexample below are new calculations for the repository recurrence;
they are not theorems quoted from that paper.

## Exact denominator lower bound

The retained denominator obeys

`D_(n+1) = C D_n^d - D_(n-1)`, with `C>=2`, `d in {2,3}`,
`D_(-1)=0`, and `D_0>=2`.

Induction gives `0<=D_(n-1)<D_n` and
`D_(n+1)>=D_n^d`. Therefore

`D_n >= D_0^(d^n)` and
`bit_length(D_n) >= floor(log2(D_0))*d^n + 1`.

The bound does not depend on the matter equations, constraints or a fitted
growth rate. Lower-degree compilation changes the exponential base; a
smaller prepared denominator changes the prefactor. Neither makes this
recurrence polynomial in update count.

## Why gcd cancellation cannot rescue protected44

Each protected diagonal pair has equal linear recurrence coefficient:
`p_next=A_n p-p_old`, `q_next=A_n q-q_old`. Thus

`W_n = p_n q_(n-1)-q_n p_(n-1) = D_0 != 0`.

If `g_n` divides every current integer numerator and denominator, it divides
`p_n` and `q_n`, hence divides `W_n=D_0`. Even a passive reduction of the
current bank can remove at most `log2(D_0)` bits. It cannot remove the
exponentially growing denominator. In the executed preparation, the gcd of
the full old/current bank remains 1. More generally the global ideal
generated by both banks is preserved by this integer polynomial map and
its integer polynomial inverse, since all update polynomials have no
constant term. This latter statement concerns the complete lattice bank;
it does not assume nodewise factor preservation for spatial couplings.

## Raw scale affects the next physical ratio

For the two-channel scalar reference `f=0`, `d=2`, `C=2`, take
`(D_old,P_old)=(1,1)` and `(D,P)=(3,2)`. The next ratio is `11/17`.
Multiply both retained banks by 2: both old and current ratios are
unchanged, yet the next ratio becomes `46/70=23/35`.
The unchanged Engine confirms this for every carry `r=0,...,5` and
inverts every full state exactly.

The cause is the different scaling of the homogeneous degree-d update and
the linear subtraction of old memory. A common-factor canonicalization
also maps distinct raw states to the same state if its scale is discarded.
Storing scale/history elsewhere would need an explicit reversible local
polynomial construction and a complete <=48-channel ledger. None is
provided by a host gcd call. The first zero-old-memory step alone can hide
this issue; it is not a valid trajectory-level gauge test.

```bash
python -m validation.synthesis.bitgrowth_algebra --out runs/synthesis/bitgrowth_algebra.json
```

The command verifies 7,056 signed scalar/carry cases against the exact
ratio identity and runs the existing cubic protected44 scalar/dust model
for six updates on 27 nodes at fixed `h=1/16`, endpoint `3/8`. Every
retained old/current/remainder entry agrees with the independent reduced
integer oracle; per-step inverse and full rewind pass. All six carries
occur. Uniform denominator, the exact lower bound and all 81 Wronskians
are checked at every checkpoint.

## Concrete next construction target

Keep this source-only benchmark as a rejection test for proposals to
"just divide the common scale". An admissible improvement must change the
encoding or recurrence algebraically, preserve all retained information,
and demonstrate smaller bit growth together with the same physical
endpoint accuracy and constraints. Candidate factor-coordinate or
low-degree reversible shear encodings need their own polynomial inverse,
locality/degree/allocation proof and all-carry tests; they remain hypotheses.
Until then, minimal compatible prepared D0 is a limited cost/perturbation
tradeoff, and shorter controlled horizons remain necessary.
