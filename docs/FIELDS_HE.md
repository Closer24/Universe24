# שדה ופנייה: רכיבים כלליים, בחירות של המודל

המטרה היא לכתוב כל חישוב פעם אחת. המודל שלנו בוחר איך להשתמש בו, ואפשר
להחליף שדה או כלל פנייה בלי לערוך את המנוע ובלי להעתיק את החישובים.

לכל פיצ׳ר פיזיקלי חדש מתחילים ב־[נוהל ההרחבה](PHYSICAL_FEATURES_HE.md).

## מי עושה מה

| רכיב | אחריות | מה המודל שלנו בוחר |
| --- | --- | --- |
| `ScalarField` | שקלול ששת השכנים, הערך המקומי והמקור, כולל שארית חלוקה | משקל 1 לכל שכן, משקל 0 לערך המקומי, מקור לפי מספר החלקיקים בתא |
| `gradient` | הפרשים בין שכנים נגדיים בשלושת הצירים | להשתמש בגרדיאנט של השדה הסקלרי כקלט לפנייה |
| `FieldTurning` | חישוב דחף, צבירת שאריות וחילופי תנע שווים והפוכים | להתעלם מרכיב הגרדיאנט שבציר התנועה הדומיננטי |
| `advance_movement` | תקציב תנועה ובחירת צעד אחד לשכן | מגבלת המהירות מהגדרות הסימולציה |
| `fields/policies.py` | חישוב מקור, בחירת טווח והחלטה על המשך עדכון | מקור אחיד לפי תפוסה, איפוס ערכים שליליים וכלל הפעילות המקורי |
| `CurrentFieldModel` | חיבור כל הרכיבים לרשומות התא והחלקיק | שדה שאינו שלילי והבחירות המפורטות לעיל |

כאן ״פנייה״ היא שינוי התנע בתגובה לשדה. הכלל הנוכחי מסיר רכיב בציר
הדומיננטי; הוא אינו סיבוב גאומטרי בזווית ואינו משתמש בטריגונומטריה.

## בחירת שדה אחר מתוך אותו חישוב

הדוגמה הבאה מגדירה הרכב חלופי לצורך ניסוי. יצירת העולם אינה מריצה אותו.
הערך המקומי מקבל משקל 1, לצד ששת השכנים, והמכנה נקבע באותו `Config`
שמשמש גם לבדיקה של השאריות במצב הפיזיקלי.

```python
from event_universe import Config, Simulation
from event_universe.fields import ScalarField

world = Simulation(
    Config(field_den=8),
    field=ScalarField(neighbor_weights=(1, 1, 1, 1, 1, 1), self_weight=1),
)
```

לשדה בעל חישוב אחר מממשים את הפעולה
`advance(sample, neighbors, *, source, denominator)` לפי `ScalarFieldRule`.
הקלט כולל ערך מקומי ושארית, שישה ערכי שכנים, עוצמת מקור ומכנה. הפלט הוא
`ScalarSample(value, remainder)`. אין צורך בירושה. הערכים חייבים להיות
שלמים חסומים, והערך המוחלט של השארית קטן מהמכנה.

לרכיב אין גישה לעולם, לזהויות המקורות או להיסטוריה. הוא לא שומר מצב משתנה
בתוכו. המקור מחושב מחוץ לרכיב; במודל שלנו הוא נקבע לפי התפוסה בתא.
כאשר הדגימה, השכנים והמקור כולם אפס, החוק חייב להחזיר דגימת אפס. זהו
התנאי שמאפשר למנוע לדלג על תאים ריקים שאינם מושפעים מהסביבה.

שדה שמועבר דרך `field=` ממשיך להתעדכן גם אם רק השארית שלו השתנתה.
כך שדה יכול לצבור שינוי קטן במשך כמה צעדים לפני שערכו השלם משתנה.
המודל המקורי שומר במפורש על כלל הפעילות הקודם לצורך תאימות. ניתן להעביר
`field_activity=` כדי לבחור כלל אחר, שמקבל דגימה קודמת, דגימה חדשה וספירת
מקורות ומחזיר `bool`. הכללים הזמינים נמצאים ב־`fields/policies.py`.

## בחירת כלל פנייה אחר

פונקציית הכיוון מקבלת תנע ווקטור שדה מקומי ומחזירה שלושה רכיבים שלמים.
היא רק בוחרת את הווקטור לתגובה. `FieldTurning` ממשיך לטפל במכנה, בשאריות,
בגבולות המספרים ובתנע הנגדי של השדה באותו מימוש משותף.

```python
from event_universe import Simulation
from event_universe.dynamics import FieldTurning
from event_universe.dynamics.turning import full_response

world = Simulation(turning=FieldTurning(select_direction=full_response))
```

בדוגמה זו מגיבים גם לרכיב האורכי. אפשר להעביר יחד `field=` ו־`turning=`
ולבחור כל אחד מהם בנפרד. בלי הפרמטרים האלה, המודל הנוכחי נשמר בדיוק.

## איך יודעים שההפרדה עובדת

| קובץ בדיקה | מה הוא בודק |
| --- | --- |
| `tests/test_scalar_field.py` | שדה משוקלל, ערכים חתומים, שאריות וגבולות מספרים |
| `tests/test_turning.py` | כללי כיוון שונים מעל אותו חישוב, דחפים קטנים ושימור תנע מקומי |
| `tests/test_current_field.py` | התוצאה המדויקת של השדה שלנו, המקור לפי תפוסה וכלל הפנייה שלנו |
| `tests/test_field_composition.py` | החלפת שדה וכלל פנייה דרך `Simulation`, ותוצאה לא תקינה שנדחית לפני כתיבה |
| `tests/test_architecture.py` | הרכיבים הכלליים אינם תלויים במודל או בעולם, והחשבון הפיזיקלי נשאר בשלמים |

לבדיקות התנועה, הגאומטריה, המדידות ולטבלת הקלטים והתוצאות המצופות ראה
`TEST_EXPECTATIONS_HE.md`.

בבדיקת ההחלפה משתמשים בשדה בדיקה שנשאר בתא המקור ואינו מתפשט, ובתגובה
מלאה לווקטור. זו עדות שהחיבור עובד, ולא אימוץ של חוק פיזיקלי חדש.
בנוסף נשמרת השוואת מצב מלאה לגרסה הקפואה בכל 278 הצעדים של שלושת תרחישי
הרגרסיה. כל הרצת מנוע בבדיקות נכללת ב־`artifacts/test-runs.html`.

## גבול ההרחבה הנוכחי

החיבור תומך בשדה סקלרי אחד בתוך מבנה התא הקבוע. החישוב הכללי יכול להחזיר
ערכים שליליים, אך המתאם שלנו מאפס תוצאה שלילית ואת השארית שלה. שדה וקטורי,
כמה שדות בו־זמנית או שינוי מדיניות הסימן מחייבים הגדרה נפרדת של מבנה המצב
וההתאמה למנוע ולמדידות. החלפת חוק פיזיקלי בניסוי מחייבת גם זהות מודל ותיעוד
נפרדים, כמוגדר ב־`SIMULATOR_DEFINITIONS.md`.
