# Strict single-edge support

Every active tensor monomial must be local under the declared contract. For
node gears this means the target node and at most one face neighbor. For a
physical link gear, include both endpoints of the stored link when counting
its support. A product involving two differently directed links can touch
three vertices even if both are stored at the same base node.

The strict support validator checks that stronger geometric condition. A
legal tensor still needs an inverse-dependency audit, a valid integer seed,
and a physical interpretation justified independently of storage metadata.

The earlier 472-type mediator experiment extended the retired field assembly.
Its exact original identities, changed dynamics and negative physical controls
remain [historical](archive/pre-fixed-six/docs/SINGLE_EDGE_IMPLEMENTATION.md).
The earlier counts and electromagnetic readout results do not describe the
current 48-channel reference default.

Current local examples use their declared fixed-six tensors. See
[MODEL](MODEL.md), [the experiment index](../experiments/geometry/README.md),
and the current live support inventory rather than copying a historical
support certificate to a different tensor.
