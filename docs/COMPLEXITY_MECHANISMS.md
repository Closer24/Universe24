# Local complexity mechanisms: what now acts on the board

This investigation follows the six-part audit in PR #38 on production main
`7d238e84a2167a4d3fe7bc7942da0cbf97bd29b2`. Six agents implemented and tested
separate optional constructions, then coordinated a bounded composition in
[issue #17](https://github.com/Closer24/Universe24/issues/17).

The supported advance is concrete: retained local history can now change
later messages; a restricted no-change sensor can emit a causal request;
bounded memory-dependent scattering changes concentration; and signed
relations between actual clock phases supply an interference intensity.
These are mechanisms inside declared fixed tensors. They are not yet a
single law deriving Born selection or recurrent bursts with growing structure.

Production evolution is unchanged. Every new Engine candidate keeps the
fixed divisor six, old-snapshot inputs, degree at most three, single-edge
support and a complete inverse. New toy domains, preparations and negative
controls are explicit. The existing cosmology acceptance protocol is not
relaxed. See the [investigation protocol](../experiments/complexity/PROTOCOL.md).

## Why these mechanisms are more than counters

### Retained memory changes future behavior

For binary moving motif components A,B and a signed bit m, the local update
`m_next=(1-2AB)m` preserves m between coincidences and flips it on a motif.
The complete first-order map has an explicit inverse. On its prepared sector,
`u=3(F+F^-1)` embeds it exactly in the existing second-order Engine.

At the same local complete A/B/probe/receiver/readout state, two actual histories
leave different m and produce next readouts -1 and +1. Removing only the memory
coupling makes their readout histories identical. A one-site initial memory
intervention with globally identical signals changes the receiver at update 5
and its neighbor at 6, within the complete-state cone. This is operational
memory: past structure affects later dynamics, rather than merely appearing
in an observer's log.

The binary version retains an actual 0/1 gear for a controlled collision.
It must not be replaced with an arbitrary integer archive or a host threshold.
Global amplitude scaling leaves the proved Boolean sector and is reported as
a stress control, including a 129-bit stop after a complete update. Information
recovery still passes; unrestricted boundedness is not claimed.

### Local no-change can cause a request

On an invariant binary source domain,
`S=1-a_x-b_x+2*a_x*b_x` is the exact equality predicate for consecutive
retained values. The fixed alarm input is `3*marker*S`. Its a/b values remain
Boolean on a proved period-four response. A downstream retained wave reads
the alarm and propagates: first message at the source at update 2, at neighbors
at 3 and at distance two at 4. Label exchange, equal total source amplitude,
unmarked and disconnected controls distinguish the cause.

This is a useful local actuator, but its observed property is unchanged input,
not unchanged complexity. A structural-novelty sensor must recognize already
learned cycles such as the period-two counterexample and preserve its learning
history. A polynomial valid only on bits cannot test equality of arbitrary
unbounded integers. The domain is part of the model.

### Bounded scattering changes concentration

The rotor's Boolean collision swaps opposite messages according to retained
memory, then updates that memory by message parity. Two banks separate local
collision from neighbor transport; both the first-order map and its inverse
are explicit. This avoids the integer blow-up of the earlier naive feedback
families. Messages/memory stay in 0/1 and density in 0/1/2.

Matched complete preparations and disconnected controls show that memory
really changes routing and concentration. In L=5 the intervention changes the
number of detected toy concentration episodes from 16 to 15 over 160 updates.
That is causal feedback evidence, not a successful growing universe. The
stored density is constrained to equal message occupancy; relabelling it as
independent reference matter would incorrectly replace the original target.

All three mechanisms above have only C0 events on their stated preparations.
Their inputs are multiples of three, so remainders stay fixed. Useful causal
memory and scattering therefore do not require forcing the arithmetic C2
classification. No claim of indefinite structural growth follows from C0 either.

## The constructive clock-to-intensity connection

Use an integer triangular phase basis `z=x+y*w`, `w=exp(i*pi/3)`. Six unit
phases are represented by `(1,0),(0,1),(-1,1),(-1,0),(0,-1),(1,-1)`.
The local rotation `R(x,y)=(-y,x+y)` satisfies `R+R^-1=I`. Consequently
ordinary gears with `u=3b` and preparation `a=R^-1 b` realize this six-state
clock exactly, with no external time injection.

Declare the signed pair coupling by phase difference:

```text
K = (2,1,-1,-2,-1,1)
C_pair = (1/2) sum_hk K(p_h-p_k)
       = x_total^2 + x_total*y_total + y_total^2.
```

The equality follows from the phase vectors' invariant positive quadratic
form. The expanded reader is an actual local degree-two tensor. All 498
clock/detector preparations follow the expected six-phase path and rewind.
This supplies an interference-intensity construction from relative clock
relations; it is not a novel probability postulate or a quantum derivation.

Signs are essential. Two equal-phase locked clocks and two antiphase locked
clocks have the same number of persistent relations but intensities 4 and 0.
History count, history diversity and unsigned persistent-pair count fail in
5,892, 5,964 and 5,820 of the 6,864 normalized branch-pair comparisons.
The signed contrast matches all, because of the proved geometric identity.
A global common phase leaves every intensity unchanged.

The actual detector still has `P(click)=min(1,q/3)` in the tested uniform-
remainder preparation. Normalizing q as a probability is still a reference
assumption. Adding a factor favoring unsigned complexity to fixed Born
weights changes their ratios, with measured total-variation deviations up to
1/3 in the declared grid. A physical interaction that changes the state first
is a different hypothesis and must be tested against that changed state.

The missing interface is therefore not another unsigned count. It is a
declared physical excitation, coherent-state encoding, apparatus ensemble,
exclusive retained outcome and correct conditional evolution. The clock
prototype has no new Bell-locality exception or physical-metric clock claim.

## Finite organization and the unchanged complete goal

The spatial-archive candidate distinguishes a repeating carrier macrostate
from a different full state. At L=5/7 its memory-pattern count rises
`0,1,2,3,3,3,3` across six macrocycles. A no-read control keeps identical memory
but removes its response, and same-law initial-memory interventions can change
later response. Nevertheless the normalized pattern at cycles 3 and 6 agrees
while magnitude doubles. Three-observation fixed-site persistence is zero.
The carrier never reads this archive, so reassembly timing is not feedback-
controlled in that construction.

The full target remains: at least four separated **reference-board**
reassemblies, strictly increasing persistent structural proxies across them,
causal feedback and stagnation attribution, and complete rewind. Neither a
periodic carrier, bounded parity register, random diversity nor larger integer
is substituted for that target. Any finite alphabet/cube also has a finite
capacity; unbounded cumulative organization requires an explicit extension
or a justified different observable, not a changed success threshold.

648 complete-state cone comparisons. Equal-amplitude static versus alternating

both effects disappear when only the alarm influence is removed.

This includes a narrow concentration-timing result: at L=5 with the declared
memory intervention, the final toy-density episode is at update 74 versus 75;

episode times agree despite different density fields. L=3 never meets the
