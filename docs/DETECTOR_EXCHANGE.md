# Detector exchange: implementation index

## Authoritative model definition

The complete user-defined external Detector exchange now has one home:
[central model specification, section 4](https://docs.google.com/document/d/1jPBMb-1BoCH8Qo6y5E-j0H0ANWzbHmkO9l-9t2pxSOQ/edit).
That section preserves action versus content sampling, PASS/GENERATE_RETURN,
provenance, LOCK, causal return/cancellation, timing, ownership and acceptance.
Do not maintain another copy of the law here. The [authority map](MODEL_SPECIFICATION.md)
distinguishes model definitions, candidate mechanisms and executable profiles.

The accepted quantum event action is a different existing mechanism. Do not
reopen it or replace it with the external exchange proposal. The
[candidate operation annex](NODE_GENERIC_OPERATIONS.md) proposes bounded plumbing
and fixtures, not new default probabilities or a universal physical response.

## Existing implementation boundary

Main `e5b5911ab13373e08345cf971a6ae8d7e9cb462e` has named
null/absorption and continue/localized/new_wave profiles. They do not by
themselves implement the separate PASS/GENERATE_RETURN exchange; do not relabel
their experiments as that demonstration. Current runtime semantics are unchanged.

[Wave origins](WAVE_ORIGINS.md) already preserve immutable historical
origin/parent/source information. Resolution is not deletion of the audit record.
That guarantee is distinct from the unfinished bounded local lookup, event-ID
routing, stopping and retention mechanism for returned notices. Ordinary Nodes
cannot read arbitrary remote history. Moving an active event preserves its
identity/properties without rewriting the immutable historical event.

## Integration fields still requiring a supported profile

Consult the central definition before filling these fields:

- Action eligibility, causal inputs/settings and explicit action weights.
- Return-content domain/distribution, phase, source accounting and draw convention.
- PASS routing, LOCK transitions, conflicting/repeated encounters and readout.
- Moving-event ID lifetime, safe reuse, local return routing and stopping.
- Fixed channel bounds, directional displacement/contact, Detector/model timing
  and transactional retry behavior.

The action meanings and causal requirements themselves are already defined.
Full neighbor capacity must not silently drop stock or create an unbounded queue.
Numerical/protocol candidates stay separately named until selected.

## Acceptance handoff

Use the central section 4 exchange cases and section 5 Node/Link checks.
Implementation evidence must identify the admitted profile, exact inputs,
expected outputs, draw counts, capacities and causal timing. Verify event/history
preservation separately from return-routing success. No two-Detector agreement
alone proves entanglement or a spacelike Bell violation. This index contains no
new executable behavior, experiment result or merge authorization.
