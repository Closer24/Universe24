How to enable the event graph

The causal graph records which actions caused later actions. You can enable it without quantum rules.

  1. Open the JSON tab above.
  2. Add this member to the outermost object, beside model_id. Use a comma between members.
"event_program": {
  "model": "causal-events-v1",
  "capacity": 100000
}

This is a member fragment, not a complete configuration. Keep one event_program key, then press Check configuration.

Turn off: remove the entire event_program member. There is no enabled: false switch. Removing a quantum program also removes its quantum behavior.

Capacity: maximum retained causal records for the whole run. It is not the number of ticks; exceeding the limit fails the run.

Quantum contacts and fields: import examples/quantum/localized_charge.json to select localized-contact-quantum-v1. A configured local contact creates a wave, and capture restores one localized disturbance. Classical fields are emitted only by localized sources. Wave references appear separately in recorded playback. The older local-quantum-events-v1/v2/v3 profiles still reject spatial fields. causal-events-v1 only records causal events.

Results: the runner saves causal-events.jsonl when enabled. The ordinary events.jsonl log is also written when the graph is off. The movie does not automatically draw the causal graph.
