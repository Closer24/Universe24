# Validation and research references

This directory contains independent test oracles, negative controls and historical
proposal reproductions. It is excluded from the installed `universe24` package.
These helpers cannot be selected as a supported runtime model.

The only supported execution path is `python -m universe24` with a validated
complete bundle. Reference calculations here neither supply Engine updates nor
certify an untested physical claim. The retired ADM event-board driver is
`validation.adm_reference`; former demos are test fixtures under `validation.demos`,
and historical audit commands live in `validation.tools`.

Preserved names and evidence describe their original model and limitations.
The active integration contract is in `docs/ONE_SYSTEM.md` and issue #40.
